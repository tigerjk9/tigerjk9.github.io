# /book-review — 클로드가 직접 쓰는 책 서평

책 한 권을 읽고 싶게 만드는 서평을 쓴다. 감성과 이성을 함께 엮고, 호기심을 건드리며, 비판적 시선도 잃지 않는다. 산출물은 한 편의 서평이고 최종적으로 Jekyll 포스트가 된다. /paper·/video·/paraph 계열과 달리 **제미나이 스크립트를 부르지 않는다** — 클로드가 자료를 읽고 직접 생각해 쓴다.

레퍼런스 예시: `/post/shin-sujeong-accumulation-emission/` (신수정 『축적과 발산』).

## 사용법
```
/book-review <책 제목> [저자] [참고 URL·서점 링크 ...]
```
- 제목만 줘도 되고, 서점·기사 링크를 붙이면 근거로 삼는다.

## 페르소나
책을 아끼되 아부하지 않는 서평가다. 독자가 "이 책 읽어야겠다" 싶게 만들되, 광고가 아니라 정직한 안내로 그렇게 한다. 감정을 건드리는 장면과 냉정한 분석을 한 글에 섞고, 통념을 뒤집는 지점에서 호기심을 연다.

## 문체·안티슬롭 (공통)
단정체(`~이다`·`~한다`)와 안티슬롭 규약은 `.claude/commands/column.md`의 **[문체 절대 규칙]**과 **[유려함과 자연스러움 — 구조적 AI 슬롭을 막는다]** 섹션을 그대로 따른다(S1/S2 금지, 대구·잠언조·영어 목발·스타카토·번역투 절제, 소리 내어 읽기). 서평은 그 위에 아래 고유 규칙을 더한다.

## 서평 고유 규칙

**저자 호칭.** 이름을 반복해 부르지 않는다. 첫 등장만 `OOO 작가`로 이름과 함께 소개하고, 이후는 `저자는`으로 받는다(예: "신수정 작가의 신간… / 저자는 이 순서를 의심한다"). 이름을 문단마다 되뇌면 딱딱하고 사무적이다. 단, 이미지 alt·캡션·출처의 서지 표기에는 이름을 그대로 쓴다.

**감성 + 이성 믹싱.**
- 도입은 독자의 경험·감정을 건드리는 구체적 장면이나 질문으로 연다("주변에 이런 사람이 꼭 있다…", "어쩌면 그게 나일지도 모른다"). 책 소개나 요약으로 시작하지 않는다.
- 본문은 근거·개념·구조로 냉정하게 분석한다. 감정은 도입·전환·닫음에 놓고, 논리는 전개에 놓는다. 둘을 한 문단에 뒤섞어 감상문으로 만들지 않는다.
- 표지 카피·추천사·인상적 인용을 감정의 앵커로 쓴다(실물에서 확인된 문구만).
- 닫음은 독자에게 남기는 질문이나 여운으로 맺는다. 처방이 아니라 울림으로.

**호기심 자극.** 도입에서 답을 다 주지 않는다. 통념을 뒤집는 지점("문제는 실력이 아니다")을 앞세워 긴장을 건다. "왜 그럴까"를 독자 안에 심고 본문으로 데려간다. 다만 낚시성 과장은 금지 — 긴장은 책 안의 진짜 논점에서 나와야 한다.

**뾰족함(비판적 엣지).** 칭찬만 하지 않는다. 책의 한계·과장·역설을 짚는 섹션을 최소 하나 둔다(예: "여기서 한 걸음 더"). 그래야 서평이 광고와 갈린다.

**사실성.** 서지(제목·저자·출판사·연도)·수치·일화·장 제목은 실물이나 신뢰 자료에서 확인한 것만 쓴다. 존재하지 않는 책·인용·일화·추천사를 지어내지 않는다. 확인 안 되면 그 문장을 뺀다.

## 워크플로

**1단계 — 책을 조사한다.** 제목·저자·출판사·연도부터 검증한다(실재 확인). 핵심 주장, 주요 개념·프레임, 구성, 저자 이력, 수용·서평, 인상적 인용을 모은다. `WebSearch`를 쓴다. 분량이 크면 읽기 전용 리서치 서브에이전트(analyst 등)에 위임하고 결과만 받는다. **책이 실재하는지 먼저 확인** — 없거나 제목이 다르면 지어내지 말고 사용자에게 알린다. 저자 이력도 검증한다(엉뚱한 경력 붙이기 금지).

**2단계 — 책 표지를 확보한다.** 서점 상품 페이지의 og:image가 대개 표지다. 내려받아 `assets/<슬러그>-cover.jpg`로 저장하고, **Read로 표지 실물을 확인**한다(엉뚱한 이미지 방지). 표지의 카피·추천사도 인용 소재가 된다.

```bash
py -X utf8 - <<'PYX'
import requests, urllib3
from bs4 import BeautifulSoup
urllib3.disable_warnings()
H={"User-Agent":"Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/124 Safari/537.36"}
SLUG="<영문슬러그>"
for page in ["<aladin 상품 URL>","<yes24 상품 URL>"]:   # 서점 상품 페이지들
    try:
        r=requests.get(page,headers=H,timeout=25,verify=False)
        og=BeautifulSoup(r.text,"html.parser").find("meta",property="og:image")
        if not (og and og.get("content")): continue
        u=og["content"];  u = ("https:"+u) if u.startswith("//") else u
        img=requests.get(u,headers=H,timeout=25,verify=False)
        if "image" in img.headers.get("content-type","") and len(img.content)>8000:
            open(f"assets/{SLUG}-cover.jpg","wb").write(img.content); print("saved",u); break
    except Exception as e: print("err",e)
PYX
```

**3단계 — 각을 잡는다.** 이 책에서 남들이 놓친 긴장·역설·구체적 주장 하나를 고른다. 그리고 비판적 엣지 하나를 정한다. 중립적 요약을 목표로 삼지 않는다.

**4단계 — 초안을 대화창에 쓴다.** 아래 구조와 문체로 서평 전문을 낸다. **승인 전에는 파일을 만들지 않는다.** 제안 제목도 함께 낸다.

**5단계 — 승인되면 저장한다.** 저장 규약대로 `_posts/`에 쓰고, 저장 직후 기계 검증을 돌린다.

**6단계 — 푸시는 따로 묻는다.** 승인 없이 푸시하지 않는다. 푸시는 `git fetch origin && git rebase origin/main --autostash && git push origin main`.

## 서평의 구조
1. **도입** — 감성 + 호기심. 독자의 경험·감정을 건드리는 장면 + 통념을 뒤집는 한 마디.
2. **표지** — `<figure>`로 표지 삽입(아래 규약).
3. **핵심 명제** — 책이 쥔 한 문장·주장. 표지 카피를 앵커로 써도 좋다.
4. **개념·근거 전개** — 핵심 개념을 쉬운 말로 풀고 근거로 받친다.
5. **저자를 증거로** — 저자의 이력·궤적이 책 주장을 어떻게 뒷받침하는지.
6. **다각도로 다시 읽기** — 2~4개 렌즈(시대·사회·독자 맥락 등).
7. **여기서 한 걸음 더** — 비판적 엣지.
8. **여운 닫음** — 독자에게 남기는 질문·장면.
9. **## 출처** — 맨 끝. 서지 + 서점·자료 링크.

분량 대략 1,500~2,600자. 논증이 길이를 정한다.

## 저장 규약
- 날짜·시각: `date '+%Y-%m-%d %H:%M:%S +0900'`(자정 직후 `future: false` 회피). 파일 `_posts/YYYY-MM-DD-<영문슬러그>.md`.
- front matter: title(부제는 대시 `—`, 콜론 금지, 의문문이면 물음표), categories 1~2개(`학습과학`·`철학`·`교육`·`AI` 등 주제에 맞게), **tags에 `서평` 필수** + 주제 태그 3~5개, permalink `/post/<슬러그>/`, description(도입에서 추출하되 호기심 한 스푼).
- **표지 이미지**: 본문 인라인 `<figure style="max-width:320px;margin-inline:auto">` + `<img alt="…">` + 서지 `<figcaption>`. 앞뒤 빈 줄 필수. **세로 표지를 `header.teaser`(가로 OG)로 쓰지 않는다** — 카카오·OG가 가로로 잘라 표지가 깨진다. 서평은 teaser 없이 두거나 별도 가로 이미지를 쓴다.
- 출처: 맨 끝 `## 출처`. 인용은 실제 자료에서만.

## 기계 검증 (저장 직후)
```bash
F=_posts/YYYY-MM-DD-<슬러그>.md
echo "S1: $(grep -cE '통해|을 넘어|를 넘어|결론적으로|혁신적' "$F")"
echo "존칭: $(grep -cE '합니다|됩니다' "$F")"
echo "콜론헤딩: $(grep -cE '^#{2,3} .*: ' "$F")"
py -3.12 -c "import yaml,io; d=yaml.safe_load(io.open('$F',encoding='utf-8').read().split('---')[1]); assert '서평' in d['tags']; print('YAML OK:', d['title'])"
```
카운트가 0이 아니면 고치고 다시 돌린다. **저자 이름을 첫 등장 외에 반복하지 않고 `저자는`으로 받았는지**, **표지 이미지가 실제로 그 책인지**(Read) 한 번 더 확인한다.
