# /hook — 글을 읽고 싶게 만드는 후킹 이미지 1장

## 사용법
/hook <입력> [옵션]

## 설명
블로그 포스트·영상·기사·논문을 **소셜용 후킹 이미지 한 장**(1080×1350)으로 만듭니다.
카드뉴스가 "내용을 여러 장으로 설명"이라면, 이쪽은 **"한 장으로 클릭을 유도"**입니다.
인스타·스레드·네이버에 글 링크와 함께 올리는 용도입니다.

## 실행

`$ARGUMENTS`가 비어 있으면 입력을 먼저 물어보세요.

```bash
py -X utf8 scripts/hookcard.py $ARGUMENTS
```

## 입력
- 블로그 포스트: `_posts/2026-07-27-slug.md` (front matter·`## 출처` 자동 활용)
- YouTube URL / 웹 기사 URL / PDF 경로 (카드뉴스와 동일한 추출기 재사용)

## 옵션
- `--dry-run` : 카피 JSON만 출력 (렌더·이미지 없음, 가장 저렴)
- `--image <파일>` : 사진을 직접 지정
- `--no-image` : 사진 없이 그라디언트 배경
- `--rerender <출력폴더>` : `card.json` 수정 후 재렌더 (**Gemini 미호출 = 무과금**)
- `--out <폴더>` / `--model <모델명>`

출력: `바탕화면/hookcard/<슬러그>/hook-01.png` + `card.json` + `render/`

## 디자인 스펙 (레퍼런스 실측 고정값)

캔버스 1080×1350 · 강조색 **#F0B24B**(카드뉴스의 `#f5e14e`보다 따뜻한 금색) · 좌우 패딩 96px

| 요소 | 위치 |
|---|---|
| 사진 | `(32,140)`–`(1048,1222)`, 하단 스크림으로 감쇠 |
| 아이브로우 | 금색 대시 66×6 + 라벨 30px |
| 헤드라인 | 2행, 1행 흰색 `#F6F3EA` / 2행 금색, Black Han Sans 최대 160px |
| 로고 | 좌하단 x96, 높이 52px (`prep_logo`가 만든 흰 스크립트) |
| 출처 | 우하단 우측정렬, 우단 x984, 24px 2줄 |

푸터 행(로고·출처)은 레퍼런스와 ±2px로 맞춰져 있습니다. **이 값들을 바꾸면 브랜드 일관성이 깨집니다.**

## 카피 원칙 — 요약이 아니라 도발

`line1` + `line2`를 이어 읽으면 한 문장이 되고, 끊기는 지점에서 긴장이 걸립니다.
**각 행 8자 내외**가 가장 강합니다(길면 자동 축소돼 힘이 빠짐).

프롬프트가 **3단계 사고를 강제**합니다. 주제를 되풀이하는 밋밋한 제목이 나오던 것을
막기 위해 JSON 스키마에 사고 과정을 넣었습니다(`sharp_facts` → `drafts` → `verdict`):

1. **날카로운 사실 3개 추출** — 통념 반박 / 놀라운 수치 / 이름 붙일 수 있는 구체물 / 대가·역설
2. **후보 4개 작성** — 서로 다른 유형으로
3. **세 시험으로 선별** + 고른 이유 명시

| 시험 | 질문 | 탈락 예 | 통과 예 |
|---|---|---|---|
| 구체성 | 같은 주제의 **다른 글**에 올려도 말이 되는가? | `AI 도구, 왜 겉돌았나?` | `AI는 마법? 교사가 깨부순다` |
| 정보 | 읽고 **알게 되는 것**이 있는가? | `참여의 비용, 누가 내는가?` | `카메라를 켜도 배우지 않는다` |
| 구체명사 | 만지거나 셀 수 있는 말이 있는가? | `교사의 희망, 집단적 실천인가?` | `64명 중 9명만 제대로 이해했다` |

금지: 요약형 서술문, 명사 나열 제목, **공허한 되묻기**(`~은 어떠한가?`), 훈계조, 존칭체, 콜론, 자료에 없는 사실

`validate_copy`가 존칭체·훈계조·AI 티 표현·행 길이·콜론·**추상어 위주·공허한 질문**·
단정체 어미+물음표 비문·출처 말줄임표를 검사하고 최대 2회 재작성합니다.
카드뉴스와 달리 **의문형을 허용**합니다 — 단 어미까지 의문형(`~인가?`)이어야 합니다.

## 이미지 3단 수급
1. 원자료 캡처 — YouTube 프레임 / 기사 본문 이미지 / 포스트 `<img>`
2. `gemini-2.5-flash-image` 생성 (다크 시네마틱 톤)
3. DDG 검색 → 실패 시 그라디언트 폴백

**논문 figure·흰 바탕 도표는 자동 탈락**시킵니다(`_photo_like`). 후킹 카드에 도표를 깔면
다크 디자인과 충돌하고 도표 속 글자가 헤드라인과 경쟁합니다. PDF 입력은 캡처 단계를 건너뛰고
바로 생성으로 갑니다.

## 후처리 QA (필수)
1. **사실성** — 헤드라인이 원문에 없는 주장을 만들지 않았는지. 놀라움은 자료 안의 진짜 사실에서 나와야 함
2. **출처 환각** — 저자·연도·제목이 원문과 일치하는지. 제공 정보에 없으면 지어내지 말 것
3. **이미지 육안 확인** — 생성 이미지에 글자·워터마크가 섞이지 않았는지, 톤이 어울리는지
4. 마음에 안 들면 `card.json`을 고쳐 `--rerender`(무과금)하거나 재실행(매번 다른 각도)

## 카드뉴스와의 관계
`scripts/hookcard.py`는 `cardnews.py`를 import해 캔버스·폰트·로고·이미지 수급·Edge 헤드리스
렌더를 공유합니다. **`cardnews.py`의 해당 함수를 고치면 `/hook`도 함께 영향받습니다.**
