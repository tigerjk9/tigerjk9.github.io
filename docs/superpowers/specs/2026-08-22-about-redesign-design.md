# 소개(About) 페이지 재설계 — 그래프 히어로 + 하프톤 도트 초상

2026-08-22 승인. 목업 3종(A 파티클 포트레이트 / B 에디토리얼 커버 / C 지식그래프) 비교 후
**C의 그래프 히어로 + B의 하프톤 초상** 조합으로 확정. 임용 연도 2006년 확인받아 통계에 반영.

## 배경 (사용자 요구)

- 원형 테두리 프로필 이미지가 고리타분함 → 틀을 벗어난 제시 방식
- 점·선 뇌 모양 SVG가 감각적이지 못함 → 교체
- 정적 페이지의 평면적·일률적 한계 극복

## 확정 설계

1. **그래프 히어로** (`#ab-hero`): 하프톤 도트 초상이 중심 노드(원형 액자 없음 —
   가장자리에서 점이 흩어지는 실루엣), 실제 성과 8개가 위성 노드(`#path`·`#books`·
   `#papers`·`#music`·`#dev`·`/knowledge-graph/` 앵커 = 그래프가 곧 목차).
   데스크톱(≥1024px, JS)은 절대배치 그래프 + 커서 파라랙스 + 유영 애니메이션,
   그 외(모바일·no-JS)는 스택 폴백(초상 + 노드 칩 그리드). `prefers-reduced-motion` 시 정적.
2. **숫자 밴드**: 교직 연차 `{{ 'now' | date '%Y' | minus: 2006 }}`, 저서
   `{{ site.data.published_books | size }}`, 블로그 `{{ site.posts | size }}` — 빌드마다 자동 갱신. 논문 3편 고정.
3. **걸어온 길 타임라인**: 세로 연결선 + 앰버 노드. 시대(2025–2026 → 2011–2019 역순)마다
   대표 활동 3건 노출 + `details`로 전체 기록(총 219건) 펼침. 현직 6건은 상단 카드.
4. **후속 섹션**(수상·집필·학술·음악·개발·채널·연락): 내용 유지, 새 헤더 스타일 + 스크롤 리빌.
5. **기술**: 외부 라이브러리 0(캔버스 vanilla), Pretendard는 jsDelivr dynamic-subset CSS(About 한정).
   전 스타일 `#about-app` 스코프(라이트모드 앵커 트랩 방어), 테마 전환은 MutationObserver로 캔버스 재렌더.
   기존 `assets/dot-connector-portrait.png` 재사용(추가 자산 없음). TOC 사이드바 제거.

## 구현 노트

- `_layouts/about.html`: layout `default` 기반, CSS/JS 전체 보유. `_pages/about.md`: 콘텐츠.
- **본문 마크다운은 전부 사전 렌더링 HTML로 커밋** — kramdown 중첩 `markdown="1"` 동작에
  의존하지 않기 위함(python-markdown 하네스에서 미처리 실측). 로컬 하네스 캡처 = 배포 결과.
- 활동 기록 추가 시 해당 시대 `details` 안 `<li>`로 추가하고 summary의 건수·`ab-sub` 총계를 갱신.
- 검증: 하네스(Edge 헤드리스) 다크/라이트/태블릿/모바일(iframe 390px) + 배포 후 라이브 캡처.
