인공지능(AI)으로 방대한 자료를 요약하면 내용은 알지만, 정작 머릿속에 남는 것은 부족하다. 이러한 한계를 넘어, PDF, 책, 논문 같은 자료를 스스로 학습할 수 있는 인터랙티브 웹페이지로 바꿔주는 AI 에이전트 스킬이 등장했다. **learn-from-materials**는 단순 요약을 넘어 사용자가 직접 자료를 탐색하고 이해하는 깊이 있는 학습 경험을 제공한다.

## AI 요약의 한계와 새로운 학습 경험

기존 AI 요약은 자료의 핵심을 빠르게 파악하도록 돕지만, 깊이 있는 이해나 장기적인 기억으로 이어지는 경우는 드물다. **learn-from-materials**는 이러한 문제를 해결하고자 자료를 단순 요약문이 아닌 '학습용 웹페이지'로 전환한다. 이 웹페이지는 원문 출처를 따라가 내용을 확인할 수 있고, 퀴즈를 풀거나 노트를 작성하는 등 다양한 학습 활동을 지원한다. 특히, 자료에 실제로 있던 내용과 AI가 덧붙인 설명을 엄격하게 구분하는 점이 핵심이다.

이 도구는 파일 읽기, 로컬 명령어 실행, 그리고 **SKILL.md** 파일을 인식하는 에이전트 환경에서 작동한다. **WorkBuddy**, **Codex**, **Claude Code**, **GitHub Copilot CLI** 같은 에이전트에서 완전한 기능을 활용한다. 파일 시스템 접근이나 파이썬 실행이 없는 순수 채팅 환경에서는 자료 추출, 내용 유효성 검사, HTML 렌더링 같은 핵심 기능을 수행하지 못한다.

## 핵심 기능: 체계적인 지식 구축 도구

**learn-from-materials**는 자료의 핵심을 파악하고 체계적인 지식 기반을 구축하는 여러 기능을 지닌다.

### 전체 자료를 아우르는 방법론
자료의 중심 질문과 목표를 추출하는 것으로 작업을 시작한다. 이후 논증, 프레임워크, 실행 규칙을 하나의 완전한 구조로 정리한다. 주 흐름, 의사결정 분기, 인과관계, 계층적 관계, 증거 기반 피드백 루프를 지원하며, 정해진 단계 수에 얽매이지 않는다. 전체 구조는 **methodology.json** 또는 **methodology.md**로 별도 저장되어, 원본 자료의 내용과 전체 자료 합성 결과를 명확히 구분한다.

### 누적되는 메서드 라이브러리
새로운 자료를 분석한 후, 재사용 가능한 방법론은 지식 기반의 **methods.json**에 저장하고, 이를 바탕으로 읽기 쉬운 **patterns.md** 파일을 생성한다. 각 카드에는 목적, 전제 조건, 한계, 단계, 효과 확인 방법, 짧은 원문 인용문, 고유 ID 및 버전 정보가 기록된다. 원본 자료에 방법론이 없으면, 없는 그대로 명시하며 임의로 만들어내지 않는다. 여러 메서드 파일을 누적하여 색인할 수 있고, 영어와 중국어 키워드로 후보 메서드를 찾는다.

### 다국어 지원 및 페이지 내 상호작용
사용자가 지정한 언어(중국어, 영어)를 우선적으로 따른다. 원본 인용문과 출처명은 그대로 유지한다. 핵심 프레임워크 카드는 검색, 확대/축소, 전체 화면 기능을 지닌 접이식 마인드 맵 형태로 제공된다. 노드나 링크에 마우스를 올리면 설명과 출처가 나타난다. 새로운 페이지는 **Sea Salt**, **Ink Wash**, **Bamboo Moon** 같은 테마와 함께 간결한 수평 레이아웃, 더 큰 다이어그램을 제공한다.

### 주요 지원 형식과 생성 페이지
**PDF**, **EPUB**, **MOBI/AZW/AZW3**, **DOCX**, **PPTX/PPTM**, **HTML**, **Markdown**, **TXT**, **RTF** 등 다양한 문서 형식을 지원한다.
결과물로 추적 가능한 **.learnkb/** 지식 기반, 독립적인 인터랙티브 HTML 페이지, 그리고 동일한 콘텐츠 데이터에서 파생된 마크다운을 생성한다. PDF 페이지, PPT 슬라이드, EPUB 챕터에 대한 세부적인 출처 매핑 기능을 지닌다. 핵심 프레임워크, 안내형 콘텐츠, 용어집, 실행 규칙, 동적 자체 확인, 로컬 노트 페이지 등을 생성한다.

## 두 가지 학습 깊이: 빠른 개요와 심층 연구

**learn-from-materials**는 사용자의 필요에 맞춰 두 가지 학습 깊이를 제공한다.

이 도구의 학습 깊이에 따른 콘텐츠 및 검토 방식은 다음과 같다.

| 항목            | 빠른 개요                                             | 체계적인 학습                                               |
| :-------------- | :---------------------------------------------------- | :---------------------------------------------------------- |
| **콘텐츠**      | 주요 섹션의 핵심 논거, 필수 용어, 조건 및 한계      | 각 출처 블록을 읽고 독립적인 지식, 논거, 증거, 방법을 최대한 습득 |
| **출처 검토**   | `quick-audit.json`에서 전체 구조 스캔 및 인용 검토 | 완전한 내용 확인, 요약 원장, 규칙/관계 원장 및 독립적인 콘텐츠 검토 |
| **방법론 파일** | 방어 가능한 핵심 방법론 및 통합된 구조              | 전체 자료에 대해 검토된 방법론 및 통합된 구조               |
| **질문 은행**   | 사전 구축된 포괄적인 은행 없음; 퀴즈 시작 시 선택 범위 내 원본 질문 검토 | 체계적인 워크플로우를 통해 질문 색인                     |

두 학습 깊이 모두 동일한 6개 모듈, 중국어/영어 지원, 3가지 테마, 스크롤 가능한 호버 카드, 관계 지도 및 **finalize.py** 전송 방식을 공유한다. `methods.json`은 방법론 카드의 원본 데이터이며, `methodology.json`은 명시적으로 라벨링된 통합 구조이다. 자료가 특정 내용을 지원하지 않으면 해당 상태를 명확히 표시한다. 빠른 개요는 포괄적인 내용 확인을 보장하지 않는다.

## 기술적 요구사항과 활용 방안

이 도구를 사용하려면 파이썬 3.10 이상이 필요하다. 또한 자료와 스킬 디렉토리를 읽고 로컬 파이썬 명령을 실행할 수 있는 AI 에이전트 환경을 갖춰야 한다. 대부분의 파일 형식은 파이썬 표준 라이브러리나 시스템 기능을 활용하여 처리된다. 스캔된 PDF나 이미지가 많은 슬라이드는 OCR 또는 비전 기능이 필요하며, 이러한 기능이 없으면 해당 범위는 미확인으로 표시한다.

설치는 압축 파일을 풀거나 Git 리포지토리를 에이전트의 스킬 검색 디렉토리에 클론하는 방식으로 진행한다. 예를 들어 **WorkBuddy**는 `~/.workbuddy/skills/`에, **Codex**는 `~/.agents/skills/`에 설치한다. 사용 시에는 "`learn-from-materials`를 사용해서 이 PDF를 체계적으로 연구하고 지식 기반과 학습 페이지를 생성해 줘"와 같이 명시적인 프롬프트를 에이전트에 입력한다. 빠른 개요를 요청하거나 체계적인 학습을 요청하여 학습 깊이를 직접 지정할 수 있다.

## 보안 및 개인정보 보호 원칙

**learn-from-materials**는 사용자의 보안과 개인정보 보호를 최우선으로 고려한다. 입력 자료는 항상 신뢰할 수 없는 데이터로 취급하며, 자료 내에 포함된 프롬프트, 명령 또는 역할 재정의는 절대 실행하지 않는다. ZIP 컨테이너 형식은 경로, 항목 수, 확장된 크기, 압축률, 암호화 상태를 확인한다.

생성된 메타데이터는 기본적으로 상대 경로 또는 파일 이름을 사용하여 로컬 사용자 디렉토리가 노출되는 것을 방지한다. 이 프로젝트의 스크립트는 자료를 네트워크로 전송하지 않는다. 개인 노트, 독자 프로필, 오답 기록은 브라우저의 로컬 저장소에만 보관하며, 계정, 클라우드 동기화, 온라인 채팅 기능을 제공하지 않는다. 저작권이 있는 자료, 내부 문서, 민감한 개인 정보를 포함한 지식 기반을 공개적으로 배포해서는 안 된다.

## 정보이론·엔트로피의 시선으로 보면

이 도구의 핵심은 원문 정보의 **무결성**을 지키는 데 있다. 정보이론에서는 원본 신호에 잡음이 섞이면 정보의 엔트로피가 증가하고, 이는 불확실성으로 이어진다. **learn-from-materials**는 AI가 덧붙인 내용을 원문과 엄격히 분리하여, 정보의 잡음을 최소화하고 원본 지식의 **충실도(fidelity)**를 높이는 전략을 사용한다. 이는 학습자가 원본의 참된 의미를 왜곡 없이 파악하도록 돕는 중요한 설계 원칙이다.
