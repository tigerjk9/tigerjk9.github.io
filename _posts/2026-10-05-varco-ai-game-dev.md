게임 개발은 복잡하고 다단계의 과정을 거친다. 한 줄의 아이디어에서 시작하여 기획, 에셋 제작, 프로토타입 개발, QA, 출시 판정에 이르는 여정에는 수많은 전문가와 자원이 필요하다. 엔씨(NC)가 공개한 **VARCO 게임 스튜디오**는 이 모든 과정을 **VARCO API 플랫폼**과 **클로드 코드(Claude Code)** 기반의 AI 에이전트를 활용하여 자동화하고 최적화하는 새로운 접근 방식을 제안한다.

## VARCO API 플랫폼의 역할

VARCO 게임 스튜디오의 핵심 기반은 엔씨 AI가 운영하는 **VARCO API 플랫폼**이다. 이 플랫폼은 텍스트, 이미지, 오디오, 3D 등 다양한 미디어 콘텐츠를 다루는 AI 기능을 한 번의 연동으로 호출할 수 있게 설계된다. 모든 호출 내역과 크레딧 사용량은 워크스페이스에서 관리한다.

VARCO API 플랫폼은 게임 개발에 필수적인 여러 AI 서비스를 제공한다.

| 분류 | 서비스 | 주요 기능 |
| :---------------- | :------------------ | :----------------------------------------------------------------------------------------------------- |
| **게임 AI** | **Sound** | 텍스트로 효과음·환경음 생성, 변형, 루프 처리, 음성 변환(사람 목소리 → 몬스터 음색), 잡음 제거 |
| | **3D** | 이미지 한 장으로 3D 메시와 텍스처 생성 (GLB 형식) |
| | **SyncFace** | 음성으로 입 모양·표정 블렌드셰이프 애니메이션 생성 (Voice-to-Face) |
| **미디어 AI** | **Voice** | 빠른 TTS (Lite), 감정 연기 TTS (Standard), 목소리만 바꾸는 음성 변환 (Voice Conversion) |
| | **Translate** | 용어집을 반영한 게임 채팅·콘텐츠 번역 (10개 언어 지원) |
| **비주얼 AI** | **Art Fashion** | 배경 합성, 시점 변경, 업스케일, 지우기, 인페인트, 텍스처·그래픽 합성, 가상 착장, 헤드스왑 |
| **콘텐츠 비즈니스 AI** | **Chatbot** | FAQ·RAG 기반 상담 챗봇 및 지식 관리 |
| **콘텐츠 보호 AI** | **Gentle Words** | 채팅·게시글 스팸 및 금칙어 필터링 |
| **연동** | **플러그인** | VARCO Sound 유니티 플러그인 (효과음, 루프, 크리처, 음악, 음성 에디터 내 생성) |

플랫폼 사용은 구글 계정 가입으로 시작하며, 개인 워크스페이스 또는 공용 워크스페이스를 구성한다. API 키를 발급받고 크레딧을 구매한 뒤 요청 헤더에 `OPENAPI_KEY`를 넣어 API를 호출한다. 비용은 사용량 기반 크레딧 방식으로 차감되며, API 키 유출 시 즉시 폐기하고 새로 발급해야 한다.

## VARCO 게임 스튜디오 하네스

**VARCO 게임 스튜디오 하네스**는 클로드 코드의 에이전트 15명이 게임 아이디어 한 줄을 받아 다섯 단계로 게임을 완성하는 시스템이다. 결과물은 기획 문서, VARCO로 생성된 효과음·대사 음성·얼굴 애니메이션·3D 모델·번역 문자열, 플레이 가능한 웹 또는 유니티(Unity) 프로토타입, QA 보고서, 출시 판정서 등을 포함한다.

하네스는 각 단계의 작업 성격에 따라 다른 실행 방식을 선택하여 효율성을 높인다.

| 단계 | 실행 방식 | 선택 이유 |
| :---------- | :--------------------------------- | :-------------------------------------------------------------- |
| **01 기획** | 이름 붙인 에이전트들의 지속형 협업 | 시스템·시나리오·레벨·UI 문서가 서로 조율하며 여러 번의 반복 작업을 거쳐야 한다 |
| **02 에셋 명세** | 서브 에이전트 1명 + 사용자 승인 | 매니페스트 한 벌로 충분하며, 실제 비용이 드는 단계이므로 사람의 승인이 필수이다 |
| **03 에셋 제작** | 워크플로(Workflow) 스크립트 | 에셋 목록과 검증·재작업 규칙을 코드로 명확히 정의한다 |
| **04 개발** | 엔지니어와 QA 한 쌍의 협업 | 모듈이 완성될 때마다 즉시 검사하고 버그를 주고받으며 빠르게 수정한다 |
| **05 출시 준비** | 네 가지 검사를 병렬로 실행 후 디렉터 판정 | 독립적인 검사들을 동시에 진행하고, 최종 판정은 한 사람이 기준표에 따라 내린다 |

### 팀 구성과 역할

하네스 내부의 에이전트는 맡은 업무 성격에 따라 **페이블(fable)**, **오푸스(opus)**, **소네트(sonnet)** 모델 중 하나를 사용한다. 추상적인 아이디어를 구체화하고 전체를 통합하는 작업에는 페이블, 설계·코드·교차 검증에는 오푸스, 절차가 정해진 제작 및 검사에는 소네트 모델이 적합하다.

| 단계 | 에이전트 | 모델 | 주요 업무 |
| :---------- | :----------------------- | :--------- | :------------------------------------------------------------- |
| **기획** | `game-director` | fable | 컨셉 구체화, 기획 문서 통합 리뷰, GDD, 출시 판정 |
| | `systems-designer` | opus | 코어 루프·시스템 규칙, 밸런스 CSV 및 스키마 설계 |
| | `narrative-designer` | opus | 세계관, 캐릭터, 대사 스크립트, 용어집 제작 |
| | `level-designer` | opus | 레벨 배치와 난이도 흐름, 사운드 구역, 프랍 요구사항 정의 |
| | `ux-designer` | sonnet | 화면 흐름, HUD, UI 문자열 디자인 |
| **기획·출시** | `balance-analyst` | opus | 몬테카를로 시뮬레이션으로 수치 검증, 구현 수치 대조 |
| **명세** | `asset-producer` | sonnet | 에셋 매니페스트, VARCO API 호출 순서, 크레딧 견적 산정 |
| **제작** | `sound-designer` | sonnet | 효과음, 환경음 루프, 크리처 음성 생성 |
| | `voice-director` | sonnet | 화자 캐스팅, 대사 음성, 얼굴 애니메이션 제작 |
| | `visual-artist` | sonnet | 3D 모델, 이미지 편집 |
| | `localization-specialist` | sonnet | 대사·UI 번역, 용어집·자리표시자 보호 |
| **제작·출시** | `asset-qa` | sonnet | 에셋 측정·검증, 출시 전 전수 감사 |
| **개발** | `gameplay-engineer` | opus | 웹 (Phaser 3·three.js) 또는 Unity 6 프로토타입 개발 |
| **개발·출시** | `game-qa` | opus | 테스트 계획 수립, 모듈별 검사, 버그 리포트, 회귀 테스트 |
| **출시** | `marketing-artist` | sonnet | 스토어 키 아트·캡슐 이미지, 스토어 설명 제작 |

### 크레딧 관리와 보호 장치

VARCO 게임 스튜디오는 비용 효율적인 운영을 위해 여러 크레딧 보호 장치를 마련한다.

*   **크레딧 승인:** 에셋 생성 전 반드시 견적을 제시하고 사용자 승인을 받는다.
*   **예산 차단:** 승인된 예산을 초과하는 호출은 공용 클라이언트를 통해 차단한다.
*   **호출 장부:** 모든 API 호출 내역을 `varco_ledger.jsonl` 파일에 기록한다.
*   **드라이런:** VARCO 키가 없거나 실제 호출을 원하지 않을 경우, 요청 명세와 견적만 생성한다.
*   **즉시 중단:** 인증 실패 또는 크레딧 부족 상황 발생 시 미시작 에셋의 호출을 즉시 중단한다.
*   **단가 미공개 API:** 번역, Voice-to-Face, 음성 변환 Acting 등 단가가 공개되지 않은 API는 별도 승인을 거쳐 호출한다. 미승인 시 일반 TTS로 대체하거나 얼굴 애니메이션을 제외한다.

## 사용 방법

VARCO 게임 스튜디오 하네스를 사용하려면 클로드 코드, 파이썬 3 (numpy, Pillow, requests), ffmpeg, ffprobe가 필요하다. 실제 에셋 생성을 위해서는 VARCO `OPENAPI_KEY`가, 유니티 프로토타입 개발에는 Unity 6가, 웹 프로토타입 QA에는 Playwright MCP가 선택적으로 요구된다.

설치 후 클로드 코드에 `무너지는 금고에서 코인을 모아 탈출하는 2분짜리 웹게임 만들어줘`와 같은 게임 아이디어를 입력한다. 하네스는 진행 중 두 번 사용자에게 승인을 요청한다.

1.  **컨셉 승인:** 디렉터가 작성한 컨셉의 핵심 결정 사항을 확인한다.
2.  **크레딧 승인:** 에셋 목록과 견적(우선순위별 합계, 단가 미공개 호출 수, 수동 제작 에셋)을 제시하고 전체 승인, P0만 승인, 드라이런 중 선택하게 한다.

결과물은 `games/{slug}/` 폴더에 확정본이, `_workspace/{slug}/`에 작업 기록이 저장된다.

이미 진행한 게임은 필요에 따라 특정 부분만 다시 실행할 수 있다.

| 요청 내용 | 다시 실행되는 범위 |
| :------------------------------- | :--------------------------------------------------- |
| "밸런스 수정해줘, 적이 너무 세" | 시스템 기획·밸런스 분석 → 데이터 재반영 → 구현 수치 대조 |
| "대사 음성만 다시 뽑아줘" | 3단계 중 해당 에셋만 |
| "일본어 현지화 추가해줘" | 에셋 명세에 현지화 추가 → 크레딧 승인 → 3단계 전체 |
| "드라이런 말고 실제로 생성해줘" | 키 확인 → 크레딧 승인 → 3단계 전체 |
| "버그 고쳐줘", "QA 다시 돌려줘" | 4단계 엔지니어·QA 쌍 |
| "스토어 이미지 다시 만들어줘" | 마케팅 아티스트만 |
| "출시 판정 다시" | 5단계 |

이처럼 필요한 부분만 선택적으로 재실행하는 유연성을 제공한다. VARCO API를 직접 활용하고 싶다면 공용 클라이언트를 사용하여 API 목록 확인, 파라미터 검사, 드라이런, 실제 호출, 장부 요약 등을 수행할 수 있다.

## 기타 참고 사항

VARCO API의 크레딧 단가는 공식 가격표가 공개되지 않아 추정치를 사용한다. 번역, Voice-to-Face, 음성 변환 Acting은 단가를 알 수 없어 견적 합계에 포함되지 않는다.

현재 VARCO에는 텍스트로 이미지를 생성하거나 음악을 만드는 REST API가 없다. 3D 모델의 원본 이미지는 사용자가 제공하거나 다른 도구로 만들고, 배경 음악은 유니티 플러그인을 통해 수동 에셋으로 처리한다.

하네스의 공용 클라이언트는 로컬 모의 서버로 실제 호출 경로를 검증했고, 에이전트는 드라이런으로 시험을 마쳤다. 실제 VARCO 서버를 통한 전체 흐름 검증은 아직 진행하지 않았다. 따라서 실제 키를 사용할 때 결과 확인이 필요하다. 또한 유니티 WebGL 빌드 시에는 Unity Hub에서 WebGL 빌드 모듈을 설치해야 한다.

## 쇼릴 제작 방식

VARCO 게임 스튜디오 하네스를 이용해 게임이 만들어지는 과정을 담은 1분 쇼릴 영상과 2분 제작 과정 영상이 공개되었다. 두 영상은 모두 HTML 캔버스에 모든 요소를 코드로 그려서 제작했다. 모든 장면이 시간만 받아 다시 그릴 수 있는 순수 함수 형태로 구현되어 원하는 프레임을 정확히 재현한다. 사운드는 numpy로 합성한 음악과 효과음을 사용하여 화면과 소리가 `timeline.json` 큐 시트에 맞춰 정확히 동기화된다.
