광진구청 류승인 주무관이 퇴근 후에 만든 프로젝트 21개를 한 사이트에 모았다. 포트폴리오 「딴짓하는 류주임 · Portfolio」([chris.gomdori.app](https://chris.gomdori.app))는 3D 카툰 마을을 한 바퀴 걸으며 프로젝트를 하나씩 보여 주고, 사이트에 표시된 GitHub 별은 6,300개가 넘는다. 사이트 소개에 따르면 그는 광진구청 7년 차 주무관이고, 매일 다루던 HWP 파일을 직접 뜯어보면서 프로젝트를 만들기 시작했다. 일하다 불편한 것을 도구로 만들었고, 도구는 전부 무료이며 대부분 링크만 열면 바로 쓸 수 있다. 류 주무관이 HWP 변환 도구와 법령 MCP를 만들게 된 사연은 [공무원 AI 혁신을 다룬 글](/post/public-sector-ai-culture/)에서 소개한 적이 있다.

## 스크롤하면 하루가 지나가는 마을

SNS 소개글에 따르면 이 포트폴리오는 기존 사이트를 3D 카툰 마을로 통째로 바꾼 것이다. 소개글은 프로젝트를 마을 건물에 빗댔다. 법령 MCP는 도서관, kordoc은 인쇄소, Anything은 등대다. 스크롤하면 아침에서 밤까지 하루가 지나가고, 밤에는 천문대에서 은하가 켜진다. 스크롤조차 귀찮은 사람을 위해 '자동으로 둘러보기'도 넣었는데, 소개글은 괄호를 열고 '만든 사람이 제일 귀찮아함'이라고 덧붙였다.

사이트의 마을 투어는 마을 입구에서 출발해 법령, 한글 문서, 문서 검색, 공공데이터 MCP, 웹 서비스, 에이전트 도구, 딸깍 시리즈, 지식 은하를 지나 광진구청과 연락처에서 끝난다. 마을을 건너뛰고 싶으면 '목록으로 바로 보기'를 누르면 된다. 마을 날씨에는 Open-Meteo 실시간 자료를 쓴다.

2026년 10월 기준 프로젝트 21개는 번호순으로 대표 프로젝트 3개(01~03), 공공데이터 MCP 서버 5개(04~08), 웹 서비스 5개(09~13), 지식 은하 4개(14~17), 에이전트 도구 4개(18~21)로 나뉜다. 여기에 번호 대신 `+`로 표시한 '딸깍 시리즈' 3개가 따로 있다. 사이트가 집계한 MCP 서버는 7개, 지식 은하는 4개다. 별을 가장 많이 받은 것은 법령 MCP인 korean-law-mcp(2,652개)와 한글 문서 엔진 kordoc(2,374개)이고, 문서 검색 앱 Anything(656개)이 뒤를 잇는다.

## AI 대화 안에서 공공 데이터를 찾는 MCP 서버

## 한글 문서 엔진 kordoc과 문서 검색 앱 Anything

kordoc은 HWP를 읽고 쓰는 엔진이다. 사이트 설명에 따르면 공공문서의 절반이 HWP인데 웬만한 도구는 이를 읽지 못한다. kordoc은 한컴오피스 없이 HWP·HWPX·PDF·오피스 문서·스캔 이미지 등 10가지 입력 포맷을 마크다운으로 바꾸고, 반대로 AI가 쓴 마크다운을 기안문·보고서 HWPX로 다시 쓴다. 공문서 서식은 서울시 실결재 문서 629건을 실측해 맞췄다. 잠긴 문서 열기, 깨지지 않는 표 복원, 표기법 검수(`kordoc lint`, 39개 규칙)도 한다. npm 라이브러리, CLI, MCP 서버, 데스크톱 앱 kordoc-ai 네 가지로 쓸 수 있고, 어디서 불러도 결과가 같다.

Anything은 Windows와 macOS에서 도는 데스크톱 앱이다. 파일명이 기억나지 않아도 문서 수천 건의 본문을 1초 안에 뒤져 내용으로 찾아낸다. 키워드 검색과 의미 검색을 합쳐 순위를 매기고, 임베딩과 OCR이 모두 로컬 모델이라 AI 기능을 끄면 네트워크 트래픽이 0이다. 그래서 인터넷이 끊긴 폐쇄망 PC에서도 쓴다. AI 질의응답은 선택 기능이고, 켜면 근거 문서와 쪽 번호를 함께 답한다.

## 공공 데이터를 3D로 띄운 지식 은하

공공 데이터 네 가지를 3D 은하 모양의 지식그래프로 만들었다. 별을 누르면 근거 조문과 문서가 열린다.

| 은하 | 담은 데이터 | 보는 법 |
|:---|:---|:---|
| 복지 은하 | 복지 사업 65개, 법령 인용 2,700건 이상(보건복지부 2026 사업안내 40종) | 복지 분야가 행성이고 사업은 그 둘레를 도는 입자다. 같은 법령을 근거로 삼는 사업끼리 선으로 이어져 어느 사업들이 같은 법에 뿌리를 두는지 보인다. |
| 제도 은하 | 대한민국 제도 660개, 조문 인용 10,500건 이상 | 제도 하나를 누르면 절차, 근거 법령, 막히는 지점이 한 장으로 열린다. 법령 시행 연대기를 재생하면 제도가 언제 어떻게 늘어났는지 흘러간다. |
| 학습 은하 | 2022 개정 교육과정 성취기준 51,463개(교과군 35개, 과목 783개) | 위 반구가 중학교, 아래 반구가 고등학교다. 이어지는 성취기준끼리 필라멘트로 연결해 같은 내용이 학년이 올라가며 어떻게 이어지는지 보여 준다. |
| 정부 은하 | 중앙행정기관 52곳의 공개문서 93,393건 | 표본을 뽑지 않고 색인 93,955건 중 93,393건(99.4%)을 넣었다. 기관이 행성, 문서가 입자이고, 같은 법령을 쓰는 기관끼리 선으로 이어진다. |

## 쓰는 언어와 데이터

프로젝트는 TypeScript, Rust, Python으로 만들고 MCP로 연결한다. TypeScript로는 MCP 서버·kordoc·LexDiff를, Rust로는 Anything 검색 엔진을, Python으로는 archhub-mcp·fable-ish·hermes-dashboard를 만들었다. 은하 4종과 딸깍 시리즈, 포트폴리오 페이지는 JavaScript·HTML·CSS로 짰고, 마을과 은하는 Three.js·WebGL로 그렸다. 데이터는 법제처 Open API, KOSIS, 공공데이터포털·건축HUB, 서울 열린데이터광장, 서울시 정보소통광장, KIPRIS Plus·OpenDART, 학교알리미·NEIS에서 가져온다. 웹과 MCP 서버는 Vercel·Fly.io에 올리고, 오픈소스는 GitHub와 npm으로 배포한다. 이슈와 PR은 모두 받으며, 강연·시연 요청은 GitHub 이슈나 메일로 받는다.
