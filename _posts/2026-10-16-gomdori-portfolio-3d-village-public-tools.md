광진구청 류승인 주무관은 퇴근 후 21개의 오픈소스 프로젝트를 개발했다. 이 프로젝트들은 깃허브에서 총 6,300개 이상의 별을 받았다. 류 주무관은 이 모든 결과물을 3D 카툰 마을 형태로 구현한 독특한 온라인 포트폴리오를 선보인다.

## 딴짓하는 류주임의 3D 카툰 마을

류 주무관의 온라인 포트폴리오는 3D 카툰 마을 형태를 지닌다. 방문자는 마을을 스크롤하며 아침부터 밤까지 하루의 변화를 경험한다. 밤이 되면 마을의 천문대에서는 은하가 나타난다. 이 마을 안의 건물들은 각각 류 주무관의 오픈소스 프로젝트를 상징한다. 예를 들어, **korean-law-mcp**는 도서관, **kordoc**은 인쇄소, **Anything**은 등대로 표현된다. 스크롤이 번거로운 사용자를 위해 '자동으로 둘러보기' 기능도 제공한다.

## 공공 데이터를 활용한 AI 도구들

류 주무관의 프로젝트들은 주로 공공 데이터를 활용하여 실무에서의 불편함을 해소하는 도구로 개발되었다. HWP 문서 처리, 법령 및 통계 검색 등 일상적인 업무에 필요한 기능들을 제공하며, 대부분은 무료로 사용 가능하다. 특히 클로드(Claude)나 챗GPT(ChatGPT) 같은 인공지능 대화 모델 안에서 공공 데이터를 직접 조회하는 MCP(Model Context Protocol) 서버 프로젝트들이 핵심을 이룬다.

다음은 주요 MCP 서버 프로젝트들이다.

| 프로젝트명 | 기능 요약 | 특징 |
|:----------|:----------|:----------|
| **korean-law-mcp** | 법령·판례·조례 검색 및 위임 관계 확인 | AI가 법제처 원문과 대조하여 없는 조문을 걸러낸다. 약칭 52종 자동 해석 및 조례 정비 대상 탐색 기능을 제공한다. |
| **korean-stats-mcp** | 국가통계 조회 및 분석 | 통계표 ID와 함께 공식 수치를 제공하며, 광진구 고용률 같은 지역별 통계를 상세히 찾는다. 시정연설, 신년사, 정책보고서 등 활용 분야에 맞춰 통계 요약을 지원한다. |
| **korean-patent-mcp** | 특허·상표 검색 | 키워드, IPC 분류, 출원인 등으로 특허를 찾고, 없는 특허는 [NOT_FOUND]로 명확히 답한다. 상표·디자인 검색도 지원한다. |
| **archhub-mcp** | 건축물대장 정보 조회 | 건축HUB의 건축물대장, 건축인허가 정보를 제공한다. 필지 연혁 타임라인, 가설건축물 존치 스캔, 층별 구성 통계 등 기능을 포함한다. |
| **schoolinfo-mcp** | 학교 공시 정보 접근 | 학교알리미의 공시 정보와 NEIS 급식, 학사일정, 시간표를 통합한다. HWP 첨부 파일 내 수행평가 계획까지 표로 변환하며, 여러 학교 비교 기능을 갖춘다. |
| **korean-dart-mcp** | 전자공시 분석 | 금융감독원 OpenDART 데이터를 클로드 안에서 읽는다. 임원·대주주 매매 클러스터 분석, 회계 리스크 점수(0~100점) 산정, 사업보고서 PDF·HWP 마크다운 변환 기능을 제공한다. |

## 문서 처리 및 AI 에이전트 도구

공공 데이터 도구 외에도 HWP 문서를 읽고 쓰거나, 로컬에서 문서 내용을 검색하고, AI 에이전트의 작업을 돕는 도구들을 개발했다.

다음은 주요 문서 처리 및 AI 에이전트 관련 프로젝트들이다.

| 프로젝트명 | 기능 요약 | 특징 |
|:----------|:----------|:----------|
| **kordoc** | 한글 문서 읽고 쓰기 엔진 | 한컴오피스 없이 HWP, HWPX, PDF, 스캔 이미지 등 10가지 포맷을 마크다운으로 변환하며, 마크다운을 HWPX로 되돌려 쓴다. 잠긴 문서 해독, 깨지지 않는 표 복원, 공문서 생성 규격 반영, 표기법 검수 기능을 갖춘다. |
| **Anything** | 문서 내용 오프라인 검색 | 파일명이 기억나지 않아도 PC 내 수천 건의 문서 본문을 1초 안에 검색한다. 키워드 및 의미 검색을 결합하고, 완전 오프라인으로 작동하여 폐쇄망에서도 활용 가능하다. AI 질의응답 기능은 선택 사항이다. |
| **fable-ish** | 클로드 코드 검증 게이트 | AI가 작성한 코드의 완료를 검사한다. 작업 분류에 따라 검증 깊이를 설정하고, `rm -rf` 같은 위험한 명령의 실행을 막는다. 검증 기록을 남겨 AI의 종료 선언이 유효한지 확인한다. |
| **hermes-dashboard** | 에이전트 관리 대시보드 | Hermes Agent를 웹 화면에서 관리한다. 모델 교체, MCP 서버 추가, 예약 실행, 로그 등 11개 화면을 클릭으로 처리한다. 하나의 HTML 파일로 구성되어 설치가 필요 없다. |
| **ollama-mcp-host** | 오프라인 MCP 호스트 | Ollama 같은 로컬 모델이 MCP 서버의 도구를 호출하도록 연결한다. 내부망이나 오프라인 환경에서 모든 추론이 PC 안에서 처리된다. |
| **edoc-summarizer** | 공문 AI 요약 확장 프로그램 | 공문을 한 번 클릭하면 문서 종류, 조치 필요 여부, 기한 D-day, 핵심 내용, 조치사항, 주의점 등을 요약한다. Ollama를 기본으로 사용해 문서가 PC 밖으로 나가지 않는다. 첨부 파일도 브라우저 안에서 직접 읽어 요약에 반영한다. |

## 웹 서비스와 지식 은하

류 주무관은 공공 데이터를 활용한 웹 서비스와 정보를 3D로 시각화한 '은하' 프로젝트도 선보인다.

다음은 주요 웹 서비스와 지식 은하 프로젝트들이다.

| 프로젝트명 | 기능 요약 | 특징 |
|:----------|:----------|:----------|
| **LexDiff** | 법령 AI 비교 및 분석 | 법제처의 법령과 판례를 찾아 근거를 달아 답변하며, 조문은 잘리지 않고 통째로 AI에 입력한다. 신구 조문 비교, 3단 위임 법령 및 영향 추적, 조례 벤치마킹, 실시간 판례·해석례 연동 기능을 제공한다. |
| **표준주소실록** | 주소 표준화 | 어떤 형태로 입력해도 도로명, 지번, 행정동, 좌표 등 표준화된 주소 정보를 한 행에 정리한다. 엑셀 대량 변환 및 내려받기, 지도 마커와 BI 연동, 시설관리 대시보드 기능을 갖춘다. |
| **인파레이더** | 실시간 인구밀집 상황판 | 서울 등 주요 도시 239개 지점의 실시간 인구밀집 상황을 보여준다. '지금 vs 평소 배지', 상황실 모드, A4 상황보고서 생성 등 기능을 통해 재난 안전 관리를 지원한다. |
| **광진 라이프** | 광진구 실시간 생활상황판 | 지하철 도착, 응급실 병상, 문 연 약국, 명소 혼잡도 등 광진구의 실시간 생활 정보를 지도 한 장에 모았다. PWA(Progressive Web App) 형태로 앱처럼 사용 가능하다. |
| **신규자 지식창고** | 신규 공무원 실무 지식 | 신규 공무원이 예산, 계약, 지출 등 실무 규정을 30초 안에 찾도록 돕는 검증 카드와 지식 모음이다. 광진구 법규에 맞춰 조문 번호까지 대조했다. |
| **복지 은하** | 복지제도 지식그래프 | 65개의 복지 사업을 3D 은하 형태로 시각화한다. 같은 법에 뿌리를 둔 사업들이 성좌로 이어져 제도 간 관계를 파악한다. |
| **제도 은하** | 대한민국 제도 지식그래프 | 660개의 제도를 3D 은하로 보여주며, 각 제도의 절차, 근거 법령, 병목 지점을 한 장으로 정리한다. 법령 시행 연대기를 재생하여 제도 변화를 확인한다. |
| **학습 은하** | 교육과정 성취기준 지식그래프 | 2022 개정 교육과정의 51,463개 성취기준을 3D 은하로 구현한다. 중학교와 고등학교 성취기준을 위아래 반구로 나누고, 이어지는 기준을 필라멘트로 연결하여 학습 흐름을 보여준다. |
| **정부 은하** | 중앙행정기관 문서 지식그래프 | 중앙행정기관 52곳의 공개 문서 93,393건을 표본 없이 전부 3D 은하로 그린다. 기관은 행성, 문서는 입자, 같은 법령을 쓰는 기관끼리 성좌로 이어진다. |

## 간단한 생산성 도구 '딸깍 시리즈'

류 주무관은 혼자 사용하기 위해 만들었다가 공개한 간단한 생산성 도구인 '딸깍 시리즈' 3가지도 소개한다. 로그인이나 설치 없이 바로 사용 가능하다.

| 프로젝트명 | 기능 요약 |
|:----------|:----------|
| **점심 딸깍** | 현재 위치 근처 음식점 하나를 무작위로 고르고 도보 시간을 알려준다. |
| **교대근무 딸깍** | 인원과 근무지를 입력하면 자동으로 배정하고 엑셀이나 이미지로 내보낸다. |
| **당직 딸깍** | 명단을 입력하면 평일 1명, 공휴일 2명의 월별 당직 순번을 짠다. |

류 주무관의 프로젝트들은 TypeScript, Rust, Python 등을 활용하여 개발되었으며, 법제처, KOSIS, 건축HUB, 서울 열린데이터광장 등 다양한 공공 개방 API를 주요 데이터 소스로 사용한다. 모든 프로젝트는 깃허브와 npm을 통해 오픈소스로 배포된다.
