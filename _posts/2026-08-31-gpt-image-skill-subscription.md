클로드(Claude)는 글에는 강하지만 이미지 생성은 오랫동안 약점이었다. 그래서 그동안은 GPT의 이미지 API를 붙여 우회하는 방법을 많이 썼다. 문제는 API가 쓸 때마다 따로 요금이 붙는다는 점이다. 이 지점을 파고든 오픈소스 스킬이 gpt-image-skill이다. 별도 API 결제 없이 ChatGPT 구독만으로 GPT 이미지(gpt-image)를 생성하게 해준다.

## API가 아니라 구독을 쓴다

이 스킬의 핵심은 이름 그대로다. OpenAI의 이미지 API나 API 키를 절대 쓰지 않는다. 대신 Codex CLI와 'ChatGPT로 로그인' 인증을 거쳐, 구독에 이미 포함된 이미지 생성 기능을 불러온다. 그래서 이미지를 만들 때마다 나가던 별도 청구가 없다. 이미 ChatGPT 유료 구독을 쓰고 있다면 추가 비용 없이 이미지를 뽑는 셈이다. 스킬은 API 키(OPENAI_API_KEY)를 읽거나 전달하지 않고, API 방식 로그인도 쓰지 않도록 설계되어 있다.

## 어디서 쓰나

특정 도구 하나에 묶이지 않는다. Claude Code, Codex, 구글 Antigravity, 그리고 호환되는 로컬 에이전트에서 같은 스킬로 동작한다. 에이전트에게 이미지를 만들어 달라고 요청하면, 스킬이 Codex CLI 다리를 통해 구독 기반 생성을 수행하고 결과 PNG를 작업 폴더에 저장한다.

## 무엇을 할 수 있나

단순한 텍스트-이미지 변환을 넘어선다.

- 텍스트로 이미지 생성
- 로컬 이미지를 레퍼런스로 삼아 생성
- 만든 이미지를 이어서 편집하거나 수정
- 배경이 실제로 투명한(알파 채널) PNG 생성
- 여러 장을 한 번에 만드는 배치 생성

비율은 1:1, 16:9, 9:16, 4:3, 3:4를 자연어로 고르고, 품질도 '초안(draft)', '고품질(high quality)', '고해상 최종본' 식으로 말로 요청한다. 사용자가 적은 프롬프트는 그대로 전달되며, 스킬이 임의로 다시 쓰거나 꾸미지 않는다.

## 설치와 준비물

세 가지가 필요하다.

| 준비물 | 설명 |
|--------|------|
| Node.js 22 이상 | 스킬 실행 엔진 |
| Codex CLI | 구독 인증을 중계하는 다리 |
| ChatGPT 로그인 | 최초 1회 'Sign in with ChatGPT' 기기 인증 |

스킬 폴더를 에이전트의 skills 디렉터리에 두고 부트스트랩을 한 번 실행하면, Codex·Claude Code·Antigravity용 연결이 함께 설치된다. 로그인은 브라우저나 기기 인증으로 본인이 직접 완료해야 한다. 스킬은 비밀번호나 토큰, API 키를 요구하거나 읽지 않는다.

## 무엇을 조심할까

이 스킬은 '구독 경계'를 엄격히 지킨다. 이미지 API나 별도 과금 경로로 우회하지 않고, 다른 제공자의 이미지 생성기로 바꿔치기하지도 않는다. 낮은 추론 설정이 상위 요금제를 열어주는 것도 아니다. 즉 이 도구는 결제를 우회하는 편법이 아니라, 이미 낸 구독료 안에서 이미지 생성을 쓰게 해주는 정직한 통로다. 요금제별 이용 가능 범위는 각자의 구독 상태를 따른다.

## 정리

정리하면 gpt-image-skill은 '클로드의 이미지 약점'과 'GPT 이미지 API의 추가 요금'이라는 두 불편을 한 번에 없앤다. 이미 ChatGPT를 구독 중인 개발자나 창작자라면, API 키를 새로 발급받고 결제를 붙이는 과정 없이 곧바로 이미지 생성을 워크플로에 넣을 수 있다. 만든 곳은 GENEXIS-AI이며 오픈소스로 공개되어 있다.
