어비폰트를 만든 어비가 무료 영상 편집기 쌤컷(SsamCut)을 공개했다. 설치 없이 크롬에서 바로 쓰고, 광고와 유료 결제가 없으며, 불러온 영상은 서버로 올라가지 않는다. 수업 영상이나 학급 행사 영상을 학교 컴퓨터에서 편집해야 하는 교사에게 쓸모가 크다. 프로그램을 깔 권한이 없는 업무용 PC에서도 크롬만 있으면 된다.

개발자는 2026년 10월 29일 스레드에 올린 소개 글에서 쌤컷이 100% 무료이고 앞으로도 유료로 바꿀 생각이 전혀 없으며 광고도 달지 않겠다고 밝혔다. 공식 사이트는 공개 뒤 5일 만에 6만 3,512명이 사용했다고 적고 있다. 개발 기록에 따르면 개발은 2026년 6월 1일 시작했고 정식 오픈은 10월 25일이다.

## 쓰는 환경

| 항목 | 내용 |
|---|---|
| 시작 | 구글 계정으로 로그인 |
| 브라우저 | PC·노트북의 크롬 권장, 엣지도 대부분 동작 |
| 휴대폰 | 아이폰 사파리, 안드로이드 크롬에서 베타. 홈 화면에 추가하면 앱처럼 열림 |
| 영상 파일 | 서버로 올리지 않고 브라우저 안에서 편집·내보내기 |
| 내보내기 | MP4, 워터마크 없음 |
| 비용 | 무료, 광고 없음 |

개발자 소개 글은 PC, 모바일, 아이패드를 모두 지원한다고 했지만, 공식 사이트는 휴대폰 사용을 아직 베타로 표시하고 PC의 크롬을 권한다. 긴 수업 영상은 PC에서 편집하는 편이 안전하다.

## 수업에서 쓰는 장면

공식 사이트의 교사용 안내는 수업 영상에서 자주 하는 일을 쌤컷 기능과 짝지어 둔다.

| 하고 싶은 것 | 쌤컷 기능 |
|---|---|
| 말이 끊긴 부분, 실수한 부분 정리 | 타임라인 컷 편집(자르기·붙이기·순서 바꾸기) |
| 소리 없이 보는 학생을 위한 자막 | 음성 인식 자동 자막 |
| 핵심 개념, 문제 번호 띄우기 | 글자 넣기, 글꼴·색·위치 조절 |
| 초록 배경 앞에서 찍은 영상 합성 | 크로마키(오른쪽 마스크 탭) |
| 도입부 음악 | 배경 음악·효과음, 볼륨 조절 |
| 짧은 요약 쇼츠 | 9:16 화면 비율 |

이 밖에 필터와 보정, 장면 전환, 키프레임 애니메이션, 여러 트랙 편집, 속도 변경이 있다. 최근 업데이트로 컷마다 밝기·대비·채도·색온도를 따로 바꾸고, 페이드 인·아웃을 넣고, 엔딩 크레딧처럼 아래에서 위로 올라가는 글자를 고를 수 있게 됐다. 학예회나 체험학습 영상 끝에 참여 학생과 도와준 분들을 띄우는 데 바로 쓸 만하다.

## 수업 영상 편집 순서

교사용 안내가 제시하는 기본 흐름은 여섯 단계다.

1. 크롬에서 `ssamtool.com/tool/cut`을 열고 구글 계정으로 시작한다.
2. 촬영한 수업 영상을 편집 화면에 끌어다 놓는다.
3. 필요 없는 부분을 자르고, 왼쪽 자막 탭에서 자동 자막을 만든다.
4. 제목과 핵심 개념을 글자로 넣는다.
5. 유튜브용은 16:9, 요약 쇼츠는 9:16으로 맞춘다.
6. MP4로 내보내 유튜브나 학급 커뮤니티에 올린다.

자동 자막은 자막 탭에서 언어를 고르고 자동 자막 만들기를 누르면 된다. 처음 한 번은 음성 인식 모델을 내려받느라 시간이 걸린다. 자막은 내 컴퓨터에서 만들기 때문에 걸리는 시간도 컴퓨터 성능에 따라 달라진다. 음성 인식 결과는 고유명사나 교과 용어에서 틀리기 쉬우니 내보내기 전에 한 번 훑어보는 편이 좋다. 초록이나 파란 배경은 클립을 고른 뒤 마스크 탭의 크로마키를 켜서 투명하게 만든다.

## 알고 쓰면 덜 잃는 것

가장 먼저 챙길 것은 저장 위치다. 프로젝트는 지금 쓰는 브라우저 안에만 저장된다. 브라우저의 사이트 데이터를 지우면 함께 지워지고, 다른 컴퓨터나 다른 브라우저에서는 보이지 않는다. 사이트 안내도 집 컴퓨터에서 이어서 편집할 수 없으며, 다른 컴퓨터에서 하려면 영상 파일을 옮겨 다시 불러와야 한다고 적는다. 재부팅 때 초기화되는 공용 PC나 컴퓨터실이라면 작업이 끝날 때마다 MP4로 내보내 두어야 한다.

영상 용량도 신경 쓸 부분이다. 업데이트 기록에 따르면 4K·5K 같은 큰 영상은 720p 사본을 자동으로 만들어 미리보기하고 내보내기는 원본 화질로 한다. 브라우저 저장 공간이 모자라면 PC의 원본 파일에 바로 연결하고, 프로젝트 목록의 저장 공간 메뉴에서 사본과 임시 파일을 정리할 수 있다. 편집 엔진이 열지 못하는 HEVC(H.265) 영상은 알림의 H.264로 바꾸기 버튼으로 변환한다. 아이폰을 고효율 설정으로 찍으면 HEVC로 저장되는 경우가 많아서, 학생 활동을 휴대폰으로 찍었다면 이 버튼을 만날 가능성이 높다.

학생 얼굴이 나오는 영상은 따로 생각해야 한다. 영상이 서버로 가지 않으니 편집 단계의 부담은 덜하지만, 공개는 별개 문제다. 사이트도 영상을 공개할 때는 학교의 초상권·개인정보 지침을 따르라고 안내한다.

## AI 앱에서 대화로 편집하기

쌤컷은 Claude와 ChatGPT의 커스텀 커넥터(MCP)를 지원한다. MCP는 AI 앱이 다른 서비스의 기능을 직접 불러 쓰게 하는 연결 규격이다. 연결하면 AI가 화면을 보고 버튼을 누르는 대신 쌤컷의 자르기·자막·효과·내보내기 기능을 바로 호출한다.

1. AI 앱 설정의 커스텀 커넥터에 `https://ssamtool.com/mcp`를 넣는다. Claude는 설정의 커넥터 메뉴에서 추가하고, 고급 설정은 비워 둔다.
2. 연결을 누르면 열리는 쌤툴 창에서 구글 계정으로 로그인하고 허용한다.
3. 쌤컷에서 프로젝트를 열어 둔 채 "말 없는 부분 잘라 주고 자막 넣어 줘"처럼 부탁한다.

요금제 조건이 있다. 연결 안내에 따르면 Claude는 무료 요금제에서도 커스텀 커넥터를 1개까지 연결할 수 있다. ChatGPT는 개발자 모드를 켜야 하고, 개인 Plus나 무료 요금제에서는 메뉴가 보이지 않거나 읽기만 되고 편집이 막힐 수 있다(2026년 11월 OpenAI 안내 기준). Claude Code에서는 `claude mcp add --transport http ssamcut https://ssamtool.com/mcp`로 추가한 뒤 `/mcp`에서 로그인한다.

AI가 할 수 있는 일은 미디어 넣기, 분할과 구간 잘라내기, 무음 자동 컷, 자동 자막과 번역 자막, 제목 글자, 필터 30종, 전환 21종, 효과음 35종, 실행 취소, MP4 내보내기다. 영상 파일을 쌤컷에 올리는 일은 AI가 못 하므로 미디어는 사람이 먼저 불러와 둔다. 결과가 마음에 들지 않으면 "방금 거 취소해 줘"라고 하면 쌤컷의 실행 취소가 실행된다.

AI가 무엇을 보는지도 알아 두어야 한다. 영상 파일 자체는 쌤툴 서버로 올라가지 않는다. 쌤툴 서버는 AI의 요청과 결과, 곧 클립 시간과 글자, AI가 요청한 작은 미리보기 그림만 전달하고 저장하지 않는다고 사이트는 밝힌다. 바꿔 말하면 미리보기 장면과 자막 글자는 내가 쓰는 AI 앱에 전달된다. 학생 얼굴이나 이름이 화면에 나오는 영상을 AI에게 맡길 때는 그 장면이 AI 앱으로 간다는 점을 감안해야 한다. AI 사용량도 각자 쓰는 Claude나 ChatGPT 요금제의 한도를 그대로 따른다. 연결을 끊으려면 편집 화면의 설정에서 AI 연결(MCP) 항목의 모든 AI 연결 끊기를 누르고, AI 앱에서도 커넥터를 지운다.

## 쌤글과의 관계

같은 커넥터 하나로 한글·워드·PDF 문서 편집기 [쌤글](/post/ssamgeul-free-web-document-editor/)도 AI가 다룬다. 두 도구는 쌤툴(ssamtool.com)이라는 무료 웹 창작 도구 모음에 속하고, 파일을 서버에 올리지 않고 브라우저 안에 저장한다는 원칙도 같다. 수업 영상을 쌤컷으로 다듬고 그 영상을 안내하는 가정통신문은 쌤글로 쓰는 식으로 한 연결 안에서 이어 쓸 수 있다.

## 무료로 내놓은 이유

어비는 약 15년 동안 어비폰트를 무료로 배포해 왔고, 쌤컷도 같은 마음으로 만들었다고 썼다. 좋은 도구가 꼭 비쌀 필요는 없으며, 작은 프로그램 하나가 누군가에게는 경제적 부담 없이 새 도전을 시작하는 계기가 될 수 있다는 생각이다. 쌤컷을 시작으로 사진 편집, 음악 편집 등 크리에이터에게 필요한 프로그램을 직접 개발해 모두 무료로 배포하겠다는 계획도 밝혔다. 10월 31일 글에서는 롱폼 영상을 넣으면 쇼츠로 자동 편집하는 기능과 유튜브·인스타그램·틱톡·스레드 자동 업로드를 11월 업데이트 예정으로 소개했다. 아직 예정 기능이니 실제 반영 여부는 사이트의 업데이트 기록에서 확인하면 된다.
