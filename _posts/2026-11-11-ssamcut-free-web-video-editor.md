어비폰트를 만든 어비가 무료 영상 편집기 쌤컷(SsamCut)을 공개했다. 설치 없이 크롬 브라우저에서 바로 쓰고, 유료 결제와 광고가 없다. 개발자는 앞으로도 유료로 바꿀 생각이 전혀 없고 광고도 달지 않겠다고 밝혔다. 공식 사이트는 2026년 10월 공개 뒤 5일 만에 6만 3,512명이 사용했다고 적고 있다.

## 쓰는 환경

| 항목 | 내용 |
|---|---|
| 시작 | 구글 계정으로 로그인 |
| 브라우저 | PC·노트북의 크롬 권장, 엣지도 대부분 동작 |
| 휴대폰 | 아이폰 사파리, 안드로이드 크롬에서 베타로 사용 |
| 영상 파일 | 서버로 올리지 않고 브라우저 안에서 편집·내보내기 |
| 내보내기 | MP4, 워터마크 없음 |
| 비용 | 무료, 광고 없음 |

프로젝트는 쓰고 있는 브라우저 안에 저장된다. 브라우저의 사이트 데이터를 지우면 함께 지워지고 다른 컴퓨터나 다른 브라우저에서는 보이지 않는다. 그래서 완성본은 내보내기로 MP4 파일을 따로 저장해 두라고 사이트는 안내한다.

## 편집 기능

| 기능 | 내용 |
|---|---|
| 컷 편집 | 타임라인에서 자르기, 붙이기, 순서 바꾸기, 여러 트랙 |
| 자막·텍스트 | 글자 넣기, 음성 인식 자동 자막, 글꼴·색·위치 조절 |
| 음악·소리 | 배경 음악과 효과음 올리기, 볼륨 조절, 속도 변경 |
| 효과·전환 | 필터, 보정, 마스크와 크로마키, 장면 전환, 키프레임 애니메이션 |
| 화면 비율 | 16:9, 9:16, 1:1 전환 |

자동 자막은 왼쪽 자막 탭에서 언어를 고르고 자동 자막 만들기를 누르면 된다. 처음 한 번은 음성 인식 모델을 내려받느라 시간이 걸린다. 초록이나 파란 배경은 클립을 고른 뒤 마스크 탭의 크로마키를 켜서 투명하게 만든다.

## AI 앱에서 대화로 편집하기

쌤컷은 Claude와 ChatGPT의 커스텀 커넥터(MCP)를 지원한다. 연결하면 AI가 내 쌤컷 편집 화면을 직접 편집한다.

1. AI 앱 설정의 커스텀 커넥터에 `ssamtool.com/mcp`를 넣는다.
2. 구글 계정으로 쌤툴에 로그인하고 허용을 누른다.
3. "말 없는 부분 잘라 주고 자막 넣어 줘"처럼 대화로 편집을 맡긴다.

이때도 영상 파일은 서버로 올라가지 않고, AI는 프로젝트 정보와 미리보기 화면만 본다. 같은 연결로 한글·워드·PDF 문서 도구인 쌤글도 AI가 편집한다.

## 무료로 내놓은 이유

어비는 약 15년 동안 어비폰트를 무료로 배포해 왔고, 쌤컷도 같은 마음으로 만들었다고 썼다. 좋은 도구가 꼭 비쌀 필요는 없으며, 작은 프로그램 하나가 누군가에게는 경제적 부담 없이 새 도전을 시작하는 계기가 될 수 있다는 생각이다. 쌤컷을 시작으로 사진 편집, 음악 편집, 문서 편집 등 크리에이터에게 필요한 프로그램을 직접 개발해 모두 무료로 배포하겠다는 계획도 밝혔다.
