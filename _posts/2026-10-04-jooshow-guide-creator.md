## JooShow, 무엇인가

JooShow는 웹 기반 사용법 가이드를 쉽고 빠르게 제작하도록 설계된 브라우저 확장 프로그램이다. 구글 크롬, 네이버 웨일, 마이크로소프트 엣지 등 크롬 웹스토어를 지원하는 브라우저에 한 번의 클릭으로 설치한다. 이 도구는 **회원가입**이나 **로그인** 절차가 필요 없다. 모든 사용자 데이터와 스크린샷은 전적으로 사용자 브라우저의 로컬 저장소에만 보관된다. **공유 링크**를 생성할 때만 해당 가이드의 이미지와 설명이 서버로 전송된다. 이미지에서 텍스트를 추출하는 **OCR** 기능 또한 기기 내부에서 처리된다. 개인정보 보호를 최우선으로 고려하는 설계 방식이다.

## 가이드 제작의 시작: 스텝 레코더

JooShow의 핵심 기능은 **스텝 레코더**이다. 이는 사용자가 웹사이트에서 클릭하고 입력하는 모든 동작을 기록하여 가이드 초안을 자동으로 생성한다.

1.  **녹화 시작**: JooShow 팝업에서 **스텝 레코더 시작** 버튼을 누르거나, **Alt+Shift+R** (Mac에서는 **⌥⇧R**) 단축키를 사용한다. 확장 프로그램 아이콘의 배지가 'REC'로 바뀐다.
2.  **사용법 시연**: 평소처럼 메뉴를 열고, 버튼을 누르고, 텍스트를 입력하는 등 가이드로 만들 과정을 웹사이트에서 진행한다.
3.  **자동 기록**: 사용자가 클릭할 때마다 다음 세 가지가 자동으로 진행된다.
    *   해당 화면의 스크린샷이 찍힌다.
    *   클릭 위치에 번호 마커가 자동으로 붙는다.
    *   클릭한 요소의 텍스트나 역할을 분석하여 "'저장' 버튼을 클릭합니다"와 같은 한국어 설명 문장이 자동으로 생성된다.
4.  **중간 조절**: 녹화 중 팝업을 다시 열면 **일시정지**나 **마지막 스텝 삭제** 기능을 사용하여 잘못된 클릭을 바로잡을 수 있다.
5.  **녹화 정지 및 편집**: **Alt+Shift+R** 단축키를 다시 누르거나 팝업의 정지 버튼을 클릭하면 녹화가 끝나고, 자동으로 편집 화면이 열린다.

단, 브라우저 내부 페이지(예: `chrome://settings` 등)나 크롬 웹스토어에서는 확장 프로그램이 동작하지 않으므로 일반 웹사이트에서 시연해야 한다. 자동 생성된 설명이 어색하면 편집 화면에서 직접 수정한다.

## 다양한 캡처 도구

JooShow는 스텝 레코더 외에도 강력한 캡처 도구들을 제공한다. 이 도구들은 가이드 제작 외에 일상적인 캡처 작업에도 유용하다. 모든 캡처 결과는 클립보드에 즉시 복사되며, 미리보기 카드로 바로 확인한다.

| 기능 | 설명 | 단축키 (Windows) |
|---|---|---|
| **탭 캡처** | 현재 활성화된 브라우저 탭의 전체 화면을 한 장으로 캡처한다. | Alt+Shift+S |
| **영역 캡처** | 사용자가 드래그하여 지정한 원하는 부분만 캡처한다. ESC 키로 취소할 수 있다. | Alt+Shift+A |
| **스크롤 캡처** | 지정 영역을 자동 또는 수동으로 스크롤하여 웹페이지 전체를 한 장으로 캡처한다. 화면 오른쪽 미니맵에 캡처 구간이 실시간으로 표시된다. | 팝업 버튼 |
| **텍스트 추출 (OCR)** | 지정한 이미지 영역 속 한국어·영어 글자를 텍스트로 추출하여 클립보드에 복사한다. 모든 처리 과정은 사용자 기기 내에서 이루어진다. | Alt+Shift+O |
| **데스크톱 캡처** | 브라우저 외부의 다른 애플리케이션 화면도 캡처한다. 화면 공유 선택창에서 창 또는 전체 화면을 고른다. | 팝업 버튼 |
| **화면 녹화** | 화면을 영상 파일(MP4, 미지원 환경은 WebM)로 녹화한다. 녹화 후 컷 편집 및 배속 조절 기능을 제공한다. | 팝업 버튼 |

팝업 하단의 '캡처 시 파일로도 저장' 옵션을 켜면, 클립보드 복사와 동시에 다운로드 폴더의 JooShow 폴더에 PNG 파일로 자동 저장된다.

## 편집: 가이드를 다듬는 과정

JooShow는 캡처된 가이드를 상세하게 수정하고 다듬을 수 있는 편집 화면을 제공한다. JooShow 팝업에서 **내 가이드 편집**을 눌러 언제든 편집 화면에 다시 진입할 수 있으며, 모든 수정 내용은 자동으로 저장된다.

### 스텝 카드 다루기

편집 화면에서는 개별 스텝 카드들을 편리하게 관리한다.

*   **설명 수정**: 카드의 설명 부분을 클릭하여 바로 수정한다.
*   **순서 변경**: 각 카드에 붙은 ☰ 손잡이를 끌어 원하는 위치로 이동시킨다.
*   **복사**: **이미지만** 또는 **이미지+설명** (번호와 설명이 이미지 하단에 합성된 형태)을 클립보드로 복사한다.
*   **텍스트 스텝 추가**: 이미지 없이 안내 문장만으로 구성된 스텝을 가이드 중간에 삽입할 수 있다.
*   **삭제**: 불필요한 스텝을 삭제한다. 실수로 삭제해도 **Ctrl+Z** (Mac은 **⌘Z**)로 되돌릴 수 있다.

### 이미지 편집 모달

각 스텝의 썸네일 이미지를 클릭하면 원본 크기 편집 모달이 열린다. 여기에서 이미지에 직접 주석을 달거나 민감한 부분을 가릴 수 있다.

*   **선택/이동**: 이미 그려진 주석을 선택하고 드래그하여 이동하거나 삭제한다.
*   **마커**: 클릭 위치를 표시하는 번호 마커의 위치를 정확하게 조절한다.
*   **주석 도구**: 화살표, 직선, 사각형, 타원, 자유 곡선 등 다양한 도형을 그려 강조한다. 색상과 굵기를 선택할 수 있다.
*   **텍스트**: 이미지 위에 직접 글자를 얹어 설명을 추가한다.
*   **블러**: 이름, 연락처 등 민감한 정보를 드래그 한 번으로 모자이크 처리한다.
*   **확대**: 클릭 지점을 자동으로 확대(줌 인셋)하여 작은 버튼 등도 또렷하게 보여준다.
*   **복사**: 현재 보이는 편집 결과를 저장 없이 바로 클립보드로 복사한다.

편집 모달을 닫지 않고 **←** **→** 키를 사용하여 이전/다음 스텝을 이어서 편집할 수 있으며, 변경 사항은 자동으로 저장된다.

## 내보내기와 공유: 활용도를 높인다

JooShow는 한 번 기록한 가이드를 다양한 형식으로 내보내고 공유할 수 있도록 지원한다. 편집 화면 상단의 내보내기 그룹에서 원하는 형태를 선택한다.

| 형식 | 결과물 | 활용 |
|---|---|---|
| **공유 링크** | 링크 하나 | 단톡방이나 이메일로 빠르게 전달하여 받는 사람이 로그인 없이 브라우저로 바로 가이드를 볼 수 있다. |
| **PPT** | 스텝당 슬라이드 1장 (.pptx) | 구글 슬라이드로 가져오거나 Canva에 업로드하여 수업 자료나 프레젠테이션에 활용한다. |
| **웹 문서** | 단일 HTML 파일 | 매뉴얼 파일로 보관하거나 배포한다. 받은 사람은 브라우저에서 편집하고 인쇄하여 PDF로 만들 수 있다. |
| **ZIP** | 순번이 매겨진 이미지 파일들 + guide.md (마크다운) | 노션, 깃허브, 블로그 등에서 이미지와 마크다운 텍스트를 재조합하여 콘텐츠를 제작한다. |
| **GIF** | 마우스가 클릭 지점으로 움직이는 애니메이션 데모 | 짧은 사용법 데모를 만들거나 커뮤니티에 공유할 때 효과적이다. |
| **카드뉴스** | 표지, 단계별, 엔딩 카드 세트 (인스타 4:5 / 1:1 비율) | SNS를 통한 홍보나 안내용 콘텐츠를 제작한다. |
| **전체 복사** | 이미지와 설명을 문서용으로 클립보드에 | 한글(HWP)이나 워드 문서에 바로 붙여넣어 활용한다. |

**공유 링크**는 생성 시 7일, 30일, 90일, 180일 중 만료 기간을 설정하고 선택적으로 비밀번호를 걸 수 있다. 민감한 정보가 없는지 확인 후 링크를 생성해야 한다. 링크를 아는 사람은 누구나 볼 수 있으므로, 민감한 내용이라면 비밀번호를 사용하고 다 쓴 링크는 '세션 목록'의 **공유 관리**에서 삭제하는 것이 좋다. 만료일이 지나면 서버에서 자동 삭제된다.

## AI 도우미 연결

JooShow는 클로드(Claude)나 챗GPT와 같은 AI 도우미와 연동하여 가이드를 검색하고 안내받을 수 있는 기능을 제공한다. 확장 프로그램 업데이트나 별도 로그인이 필요 없다.

1.  **연결 주소 등록**: 클로드의 채팅 입력창에서 `+` → `커넥터` → `커넥터 추가` → `커스텀 커넥터 추가`를 선택한다.
    *   이름: `JooShow`
    *   주소: `https://joo.show/mcp`
    *   인증: `로그인 없음` 으로 설정하고 추가한다.
2.  **질문하기**: "JooShow에서 ○○ 방법 찾아 줘"와 같이 JooShow를 언급하며 질문한다. AI가 JooShow 공개 갤러리에서 맞는 가이드를 찾아 단계별로 요약하고 링크를 제공한다. 처음 한 번은 도구 사용을 묻는데 '항상 허용'을 누르면 된다.
3.  **내 가이드 검색**: 자신이 만든 가이드도 공유 링크를 만든 뒤 **갤러리에 공개 신청**하면 AI 검색에 나타난다. 비공개 링크나 비밀번호가 설정된 가이드는 검색되지 않는다.

챗GPT나 클로드 코드, 커서 등 다른 AI 도우미와의 연결 방법은 JooShow의 **AI 연결 안내** 페이지에서 자세히 확인할 수 있다.

## 편의 기능과 자주 묻는 질문

JooShow는 사용자 편의를 위한 다양한 기능을 제공하며, 자주 묻는 질문에 대한 답변은 다음과 같다.

*   **단축키**: JooShow는 탭 캡처(**Alt+Shift+S**), 스텝 레코더 시작/정지(**Alt+Shift+R**), 영역 캡처(**Alt+Shift+A**), 텍스트 추출(**Alt+Shift+O**) 등 핵심 기능에 기본 단축키를 제공한다. 사용자는 팝업 하단의 '단축키 변경'을 통해 원하는 키 조합으로 직접 설정할 수 있다.
*   **개인정보 처리**: 스크린샷, 가이드, 설정 등 모든 데이터는 브라우저 로컬 저장소(IndexedDB)에만 저장된다. 서버로 데이터가 전송되는 유일한 경우는 사용자가 직접 '공유 링크'를 만들 때이며, 이때도 해당 가이드의 이미지와 설명만 업로드된다. 텍스트 추출(OCR) 역시 기기 내장 엔진으로 처리된다. 사용자 분석이나 광고 SDK는 포함되지 않는다.
*   **스텝 기록 오류**: 브라우저 내부 페이지(예: `chrome://` 설정, 웹스토어, 새 탭)에서는 확장이 동작할 수 없어 클릭이 기록되지 않는다. 일반 웹사이트에서 시연해야 한다. 새로 설치한 경우, 이미 열려 있던 탭은 한 번 새로고침이 필요하다.
*   **자동 설명의 정확성**: 클릭한 요소에서 읽을 텍스트가 없으면 기본 문장이 들어간다. 편집 화면에서 설명을 클릭하여 바로 수정할 수 있다. 가이드를 다듬는 단계에서 설명을 직접 고치는 것을 권장한다.
*   **화면 녹화 편집**: 녹화가 끝나면 컷 편집기가 열린다. 타임라인에서 구간을 잘라내고, 배속(1배~30배)을 골라 내보낼 수 있다. 4배속 이상은 무음 처리된다.
*   **저장 공간 관리**: 세션 목록 상단에 현재 사용량이 표시된다. 완성된 가이드는 **원본 정리** 기능으로 원본 스크린샷을 지워 용량을 줄일 수 있다. 이때 해당 가이드는 마커나 주석 재편집이 불가능해진다. 필요 없는 세션은 선택하여 일괄 삭제한다. 확장을 삭제하면 모든 데이터가 함께 삭제된다.
*   **Canva 연동**: 원클릭 직접 연동 기능은 준비 중이다. 현재는 PPT로 내보낸 뒤 Canva에 pptx 파일을 업로드하는 방식이 가장 빠르다. Canva에서 페이지별로 자동으로 배치된다.
