패들렛이 AI 비서와 연동되는 **MCP 서버**를 공개했다. 이제 클로드 같은 AI 비서에게 말로 지시하면 패들렛에서 원하는 작업을 직접 처리한다. 사용자는 일일이 클릭할 필요 없이 대화만으로 새로운 협업 보드를 만들거나 기존 내용을 관리하는 등 다양한 작업을 수행한다.

## AI와 패들렛 연결, MCP란
패들렛은 **MCP(Model Context Protocol)** 서버를 선보인다. MCP는 AI 비서가 사용자를 대신해 외부 서비스와 안전하게 연동하여 작업을 수행하도록 돕는 공개 표준이다. 패들렛 계정을 AI 비서에 연결하면 "프로젝트 킥오프 미팅을 위한 보드를 만들고, 다섯 가지 소개 글을 추가하라" 같은 일상 언어로 명령을 내릴 수 있다.

MCP의 핵심 원칙은 다음과 같다.

| 원칙 | 설명 |
|---|---|
| **기존 권한 유지** | AI 비서는 사용자의 패들렛 계정 권한 범위 내에서만 작동한다. |
| **권한 설정 준수** | 기존 패들렛의 공유 및 편집 권한 설정을 따른다. |
| **연결 및 해제 자율성** | 사용자가 직접 로그인하여 연결을 승인하고, 언제든지 해제할 수 있다. |

## AI 비서가 처리하는 패들렛 작업
AI 비서가 패들렛 계정에 연결되면, 사용자가 직접 수행하던 대부분의 작업을 대신 처리한다. 현재 샌드박스 기능은 지원이 불완전하며, 주로 **보드** 관련 작업에 집중된다.

AI 비서가 수행하는 주요 작업은 다음과 같다.

| 범주 | 세부 기능 |
|---|---|
| **패들렛 생성** | 새 패들렛 만들기, 기존 패들렛 재사용, 소유한 패들렛 검색 |
| **콘텐츠 읽기** | 패들렛에 게시된 글, 댓글, 섹션 내용 읽기 |
| **외형 변경** | 제목, 설명, 레이아웃, 배경, 아이콘 등 화면 설정 수정 |
| **개인 정보 설정** | 보기/게시/편집 권한 제어, 읽기 전용으로 잠금, 삭제된 글/섹션 복원 |
| **글 및 댓글** | 글 추가 및 편집 (첨부 파일 포함), 글 고정 및 연결, 댓글 및 반응 남기기, 게시된 콘텐츠 요약 요청, 자동화/제출 양식/브레이크아웃 링크 설정 |
| **수업 관리** | 한 학생이 여러 패들렛에 남긴 글/댓글 모아보기, 글 채점, 성적 시스템으로 점수 전송 |
| **학교 및 팀 관리** (관리자 전용) | 이메일/대량 멤버 등록, 초대 링크로 멤버 초대, 멤버 권한/허용 도메인 관리, 콘텐츠 안전 설정/첨부 파일 유형 관리, SAML SSO/OAuth 로그인 설정 |

## 패들렛 MCP 연결 방법
AI 비서에 패들렛 MCP를 연결하는 과정은 간단하다.

1.  패들렛에 로그인한다.
2.  클로드 등 MCP를 지원하는 AI 비서의 커넥터 설정으로 이동한다.
3.  새 커넥터를 추가하고 주소 `mcp.padlet.com`을 입력한다.
4.  승인 요청이 나타나면 승인 버튼을 클릭한다. 패들렛 로그인 화면으로 이동하여 액세스를 허용한다.
5.  AI 비서로 돌아오면 바로 사용 가능하다. 간헐적으로 재승인 요청이 있을 때 동일한 절차를 반복한다.

연결 해제는 AI 비서의 커넥터 설정에서 패들렛을 삭제하면 된다. 기존 패들렛과 게시물은 변경되지 않으며, 언제든지 다시 연결할 수 있다.

## 사용 전 확인 사항과 질문
AI 비서는 사용자 계정을 통해 직접 작업을 처리한다. 이는 글 삭제나 멤버 초대 같은 민감한 작업도 AI가 사용자 대신 수행함을 의미한다. 따라서 지시를 내리기 전에 요청 내용을 다시 한번 확인하는 것이 좋다. 모든 연결은 로그인한 사용자의 승인을 거쳐야 하므로, AI는 인간의 허락 없이 독립적으로 작동하지 않는다.

자주 묻는 질문은 다음과 같다.

| 질문 | 답변 |
|---|---|
| **유료 계정이 필요한가?** | 아니요. 무료 계정을 포함한 모든 패들렛 계정에서 사용 가능하다. |
| **AI가 접근할 수 없는 자료도 볼 수 있나?** | 아니요. AI는 사용자 계정으로 로그인하기 때문에 사용자 권한을 초과할 수 없다. |
| **샌드박스에서 작동하나?** | 아직 완전히 지원되지 않는다. 우선 보드에서 사용하는 것을 권장한다. |
| **AI가 내 패들렛을 찾지 못한다.** | 연결 승인 시 다른 패들렛 계정으로 로그인했을 가능성이 크다. 커넥터 설정에서 패들렛을 해제하고, 해당 패들렛을 소유한 계정으로 로그인하여 다시 연결해야 한다. 다른 사람의 패들렛이라면 먼저 접근 권한을 얻어야 한다. |
| **패들렛 공개 API와 같은가?** | 아니요. 공개 API는 개발자가 직접 코드를 작성할 때 사용하며, 설정 페이지에서 개발자 키를 얻는다. MCP는 AI 비서를 위한 것으로, 패들렛 로그인으로 승인한다. 둘 다 함께 사용할 수 있다. |
| **개발자가 MCP를 구축하려면?** | `padlet.com`의 `auth.md` 문서에서 클라이언트 등록 및 사용자 승인 절차를 설명한다. 개발자 디스코드 채널도 제공한다. |
