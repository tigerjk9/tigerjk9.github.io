파워포인트 문서를 만들 때 AI의 도움을 받는 방법은 다양하다. 하지만 많은 AI 도구가 단순 템플릿 채우기나 이미지 형태의 결과물을 내놓아, 막상 세부 편집을 하려면 아쉬움이 남는 경우가 많다. **슬라이드 마스터(slide-master)**는 이러한 한계를 넘어, AI 에이전트가 직접 파워포인트에서 **요소별 편집이 가능한 네이티브 PPTX** 파일을 만드는 워크플로우를 제시한다.

## 슬라이드 마스터: 무엇인가

슬라이드 마스터는 AI 코딩 에이전트 안에서 실행되는 파워포인트(PPT) 생성 워크플로우이다. 이는 별도의 앱이나 웹 서비스가 아니다. 클로드 코드, 코덱스(챗GPT 데스크톱 앱 포함) 같은 AI 코딩 에이전트에 채팅으로 명령을 내리면, AI가 정해진 절차에 따라 사용자 컴퓨터에서 PPT 파일을 생성한다.

이 워크플로우는 PDF, DOCX, 웹 URL, 마크다운, 엑셀/CSV 파일은 물론, 간단한 주제 한 줄도 입력으로 받는다. 출력물은 파워포인트에서 **요소 하나하나 클릭해 수정할 수 있는 네이티브 `.pptx` 파일**이다. 도형, 텍스트, 차트는 이미지 형태가 아니라 실제 파워포인트 개체로 존재한다. 발표자 노트, 페이지 전환, 그리고 필요하다면 음성 나레이션까지 담긴다.

작업 과정은 다음 순서로 진행된다. AI가 자료를 읽고, 브라우저 확인 페이지에서 사용자와 함께 방향과 디자인을 정한다. 이후 각 페이지를 SVG 형식으로 그린 뒤, 자체 변환기로 PPTX 파일을 만들어낸다. 예를 들어, "프로젝트 폴더에 있는 3분기 보고서 PDF로 임원 보고용 PPT를 만들어줘"라고 요청하면, AI가 자동으로 작업을 수행하고 편집 가능한 PPTX 파일을 출력한다.

## 다른 AI PPT 도구와 다른 점

슬라이드 마스터 워크플로우의 핵심 철학은 **"파워포인트에서 열어 고칠 수 없으면 PPT가 아니다"**이다. 다른 AI PPT 도구들과 비교하면 슬라이드 마스터가 가진 차별점은 더욱 명확하다.

| 방식           | 결과물                     | 파워포인트에서 요소별 편집 가능 여부 |
|--------------|--------------------------|:--------------------------------:|
| 템플릿 채우기형  | 고정 템플릿에 텍스트만 채운 PPTX | 템플릿 한계 안에서만              |
| 이미지형       | 슬라이드 = 큰 그림 한 장     | 불가                             |
| HTML형         | 웹 기반 슬라이드           | 불가 (PPTX 파일이 아님)         |
| **네이티브 편집형 (슬라이드 마스터)** | **진짜 DrawingML 도형·텍스트·차트** | 가능                            |

슬라이드 마스터는 다음 세 가지 특징으로도 다른 도구들과 차별화된다.
*   **투명한 비용**: 도구는 무료 오픈소스이며, 사용자는 AI 모델 사용료만 지불한다.
*   **로컬 데이터 처리**: AI 모델과의 통신을 제외한 모든 과정은 사용자 컴퓨터에서 실행된다. 데이터는 로컬에 남는다.
*   **플랫폼 독립성**: 클로드 코드, 코덱스(CLI 및 챗GPT 데스크톱 앱), 커서, VS Code 코파일럿 등 파일 읽기/쓰기 및 명령 실행이 가능한 다양한 AI 에이전트에서 동작한다.

이 도구는 완벽한 PPT를 한 번에 만들어주는 요술램프가 아니다. AI가 지루한 작업의 대부분을 대신하고, 마지막 다듬기는 사용자가 직접 편집 가능한 PPTX 위에서 수행하도록 돕는 생산성 도구이다.

## 슬라이드 마스터의 동작 방식

슬라이드 마스터의 작업 절차는 여러 단계를 거쳐 진행되며, 각 단계에서 사용자 개입과 자동화가 조화를 이룬다.

1.  **전략 확인**: 브라우저에 열리는 확인 페이지에서 캔버스 크기, 페이지 수, 색상, 폰트, 이미지 방식을 3단계에 걸쳐 선택한다. 사용자는 색상 견본과 폰트 미리보기를 직접 보며 선택한다. 맥킨지, 애플, 네이버 스타일 등의 내장 덱 템플릿을 선택해 작업을 시작할 수도 있다.
2.  **생성 중 라이브 프리뷰**: 슬라이드가 만들어지는 과정을 실시간으로 볼 수 있다. 수정할 부분이 있다면 화면에 클릭 주석을 남겨 AI가 반영하도록 요청한다.
3.  **완료 후 다듬기**: `exports/` 폴더에 생성된 PPTX 파일을 열어 내용을 확인한다. 필요하면 AI 에이전트와의 채팅을 통해 "4페이지 차트를 막대로 바꿔줘"와 같이 세부 수정을 계속 요청할 수 있다.

모든 덱에는 **프리텐다드(Pretendard)** 폰트(SIL OFL)가 사용된다. 폰트 파일은 저장소에 번들되어 있으며, PPTX 파일 자체에 폰트가 내장되지 않으므로, 다른 컴퓨터에서 덱을 열 때는 해당 컴퓨터에도 프리텐다드를 설치해야 한다.

## 설치와 활용

슬라이드 마스터를 사용하기 위한 설치 과정은 약 10분 정도 소요되며, 몇 가지 단계를 거친다.

1.  **Python 3.10+ 설치**: [python.org](https://www.python.org/downloads/)에서 설치할 때 "Add to PATH"를 반드시 체크한다.
2.  **AI 에이전트 설치**: 클로드 코드 또는 코덱스(CLI, 챗GPT 데스크톱 앱) 설치를 권장한다. 커서, VS Code 코파일럿 등 파일 읽기/쓰기와 명령 실행이 가능한 에이전트에서도 동작한다.
3.  **저장소 클론 및 의존성 설치**: 다음 명령어로 저장소를 받고 필요한 라이브러리를 설치한다.
    ```bash
    git clone https://github.com/byungjunjang/slide-master.git
    cd slide-master
    pip install -r requirements.txt
    ```
    이후 받은 폴더를 AI 에이전트에서 연다.
4.  **AI 이미지 생성 (선택 사항)**: 표지나 인포그래픽에 AI 이미지를 사용하려면 코덱스 CLI OAuth 로그인 또는 API 키(OPENAI_API_KEY 등) 설정이 필요하다.
5.  **PPTX 검증 도구 (선택 사항)**: 내보낸 PPTX의 패키지 무결성, 텍스트 넘침, 렌더링을 자동 점검하려면 [OfficeCLI](https://github.com/iOfficeAI/OfficeCLI)를 설치한다.

가장 흔한 사용 패턴은 모두 채팅에 자연어로 명령하는 방식이다.
*   **자료로 새 덱 만들기**: "이 PDF(경로)로 PPT 만들어줘"
*   **주제만 있고 자료가 없음**: "국내 이차전지 시장 동향 PPT 만들어줘"
*   **기존 PPTX 템플릿에 내용 채우기**: "이 템플릿 PPTX에 이 내용 채워서 만들어줘"
*   **완성된 덱 다듬기**: "이 PPTX에 발표자 노트랑 음성 나레이션 넣어줘"
*   **내보낸 PPTX 품질 점검**: "내보낸 PPTX 검증해줘"

실전 시나리오로 예를 들면, "프로젝트 폴더의 실적보고.pdf로 10페이지 내외 임원 보고 PPT를 만들어줘. 핵심 KPI를 강조하고, 톤은 절제된 컨설팅 스타일로 해줘"와 같이 구체적으로 요청할 수 있다.

## 자주 묻는 질문

**Q. 진짜 편집이 가능한가요, 아니면 그림을 PPT에 붙인 것인가요?**
**A.** 진짜 편집된다. SVG를 DrawingML로 직접 변환하므로 텍스트 상자, 도형, 차트가 모두 네이티브 파워포인트 개체이다. 색상, 위치, 문구 모두 파워포인트에서 수정할 수 있다. 차트나 표를 데이터가 연결된 실제 파워포인트 차트 개체로 뽑는 옵션도 제공한다.

**Q. 결과물이 마음에 들지 않으면 어떻게 해야 하나요?**
**A.** 4중 안전망을 갖춘다. 첫째, 생성 직후 자동 지오메트리 게이트가 텍스트 겹침, 캔버스 이탈, 어색한 줄바꿈을 글리프 폭 산수로 검출해 AI가 스스로 수정한다. 둘째, 라이브 프리뷰에서 클릭 주석으로 즉시 수정 요청이 가능하다. 셋째, 명시적 요청 시 페이지별 AI 시각 자체 검토 기능(`visual-review`)을 수행한다. 넷째, PPTX 내보내기 후 OfficeCLI 검증(`verify-pptx-export`)으로 텍스트 넘침 및 패키지 오류를 자동 검출한다. 최종 결과물이 편집 가능한 PPTX이므로 언제든 직접 고칠 수 있다.

**Q. 우리 회사 템플릿이나 브랜드 색상을 사용할 수 있나요?**
**A.** 두 가지 방법으로 가능하다. 기존 PPTX에 내용만 채우는 `template-fill` 워크플로우는 디자인 원본을 유지한다. 브랜드 아이덴티티(색상, 폰트, 로고)를 재사용 프리셋으로 만드는 `create-brand` 또는 `create-template` 워크플로우도 지원한다.

**Q. 비용은 얼마나 드나요?**
**A.** 도구 자체는 무료이다. 연결한 AI 모델의 사용료만 발생하며, 덱 분량과 이미지 생성 여부에 따라 달라진다.

**Q. 내 문서가 어딘가에 업로드되나요?**
**A.** AI 모델과의 대화에 들어가는 내용 외에는 모두 로컬에서 처리된다. 변환, 생성, 내보내기 스크립트는 모두 사용자 컴퓨터에서 실행된다.

**Q. 이 저장소는 어떻게 업데이트하나요?**
**A.** 이 워크스페이스는 [hugohe3/ppt-master](https://github.com/hugohe3/ppt-master)를 기반으로 커스터마이즈된 버전이다. 업스트림 최신화가 필요하면 새로 받은 뒤 `projects/` 폴더와 로컬 커스텀 내용을 옮겨 적용하는 방식을 사용한다. 단순 `git pull` 대상이 아니다.
