영상 편집에서 시간이 가장 많이 드는 일은 자를 곳을 찾는 일이다. 타임라인을 앞뒤로 돌려 가며 "음", "어" 하는 부분이나 말이 끊긴 구간을 하나씩 찾아야 한다. 주식회사 오늘배움이 만든 무료 영상 편집기 EasyCut은 말한 내용을 먼저 대본으로 보여 주고, 대본에서 글을 지우면 영상의 같은 자리도 함께 잘라 낸다. 맥에서만 쓸 수 있던 이 편집기가 윈도우 베타를 내놓았다.

## 대본으로 편집하는 영상

EasyCut은 음성 인식으로 영상 속 말을 글로 바꾼다. 사용자가 이 대본에서 필요 없는 문장이나 단어를 지우면 영상의 해당 구간도 함께 잘린다. 문서를 고치듯 영상을 다듬는 방식이다.

## 맥과 윈도우 환경 지원

개발자는 학교에서 쓰는 컴퓨터가 대부분 윈도우라서 윈도우 버전을 꼭 만들어야 했다고 밝혔다. 두 버전은 프로젝트 파일 형식이 같다. 맥에서 작업하던 `.easycut` 파일을 윈도우에서 그대로 열어 이어서 편집할 수 있다.

두 운영체제에서 공통으로 되는 기능은 다음과 같다.

-   영상·오디오·사진 파일을 끌어다 놓아 가져온다.
-   음성 인식(Whisper)으로 대본을 만들고, 대본에서 지운 말은 영상에서도 삭제된다.
-   "음", "어" 같은 군더더기 말을 대본에서 한 번에 지운다.
-   원클릭 무음 컷으로 말 없는 구간을 한 번에 잘라 낸다.
-   대본으로 자막을 자동 생성하고 글꼴·색·위치를 꾸민다. SRT 파일 가져오기와 내보내기를 지원한다.
-   멀티 트랙 타임라인에서 클립을 분할·이동·트림하고 속도를 조절한다.
-   자막을 입힌 MP4로 내보낸다.

맥 버전에만 있는 기능도 있다. 화면과 얼굴을 함께 녹화하면 녹화가 끝나는 즉시 트랙별로 자동 배치되고 바로 음성 인식이 이어진다. 또 Claude나 ChatGPT 계정으로 로그인만 하면 AI 편집을 쓸 수 있고, API 키를 따로 넣을 필요가 없다. 윈도우 베타 안내 문서도 맥 버전을 "녹화·AI 편집까지 포함"이라고 구분해 적었다.

## 맥 버전 README로 본 세부 기능

아래 내용은 저장소 README(맥 버전 기준)에 정리된 기능이다.

멀티 트랙 타임라인에서 클립을 옮기고 자르고 붙이며, 미리보기는 0.25~20배속, 클립 속도는 0.1~20배(음정 유지)까지 조절한다. 음성 인식 엔진은 Apple 온디바이스(설치·인터넷 불필요)와 Whisper 가운데 고른다. Whisper는 Large v3 Turbo 모델(약 574MB)을 한 번 내려받아 쓰며, 한국어 정확도가 더 높고 훨씬 빠르다. README에 따르면 2시간 녹화를 Whisper는 약 5분에 처리하고, Apple 엔진은 수십 분이 걸린다.

자막은 대본으로 자동 생성하거나 직접 추가·수정할 수 있다. 글꼴·색·배경·외곽선·위치를 정하고, SRT를 가져오거나 내보내며, 완성된 자막을 영상에 입혀 내보낸다.

링크로 가져오기 기능도 있다. 유튜브 등의 주소를 붙여 넣으면 편집하기 좋은 H.264 MP4로 받아 바로 타임라인에 올린다. 화질(720p, 1080p, 최고, 소리만)을 고르거나 일부 구간만 받을 수 있고, 업로더가 올린 한국어·영어 자막도 함께 받는다. README는 본인 영상이나 저작권자에게 이용 허락을 받은 영상만 내려받아 편집하라고 당부한다.

MKV, WebM, AVI 같은 파일은 가져올 때 자동으로 MP4로 바뀐다. H.264/HEVC 영상은 다시 압축하지 않고 포장만 바꾸므로 몇 초면 끝나고 화질 손실이 없다. VP9·AV1 등은 Mac 하드웨어 인코더로 H.264로 변환한다.

## AI 편집 (맥 전용)

AI 탭에서 Claude Pro/Max 구독이면 [Claude로 로그인]을, ChatGPT Plus/Pro 구독이면 [ChatGPT로 로그인]을 누르고 브라우저에서 로그인하면 준비가 끝난다. Claude Code나 Codex가 없으면 앱이 공식 배포본을 자동으로 설치한다. 그다음 "무음 다 잘라줘", "3분~5분 2배속"처럼 말로 편집을 요청하면 구독 사용량으로 처리한다. API 키를 따로 넣을 필요는 없다.

앱은 로그인된 Claude Code나 Codex를 내부에서 실행하되 EasyCut 편집 도구만 쓰게 하고, 사용자의 개인 설정이나 플러그인은 섞지 않는다. 원하면 Claude API 키(macOS 키체인에 저장)나 OpenAI API 키로도 쓸 수 있다. Claude Code, Claude 데스크톱, Codex 같은 외부 AI 앱에서 MCP로 EasyCut을 직접 조작하는 방법도 있다. 이 연결은 그 Mac 안(127.0.0.1)에서만 이뤄지고, 앱 지원 폴더의 비밀 토큰을 가진 요청만 받는다. AI가 한 편집은 모두 ⌘Z로 되돌릴 수 있다.

## 설치와 시스템 요구사항

EasyCut은 무료 오픈소스(MIT 라이선스) 소프트웨어다.

-   윈도우: Windows 10/11(64비트)에서 쓴다. 릴리스 페이지의 최신 Windows 버전 Assets에서 `EasyCut_…_x64-setup.exe`를 받아 실행한다. 서명되지 않은 앱이라 "Windows의 PC 보호" 창이 뜨면 [추가 정보]를 누른 뒤 [실행]을 누른다.
-   맥: M1 이상 Apple Silicon, macOS 14 이상에서 쓴다. `EasyCut-x.y.z.dmg`를 열어 EasyCut을 응용 프로그램 폴더로 끌어 놓는다. 서명·공증되지 않은 앱이라 처음 열 때 경고가 뜨면 시스템 설정 > 개인정보 보호 및 보안에서 [그래도 열기]를 누른다.

음성 인식 모델(574MB)은 처음 한 번만 내려받으면 된다. 맥 버전은 Whisper 엔진과 ffmpeg가 앱 안에 들어 있어 Homebrew 같은 추가 설치가 필요 없고, 모델은 대본 탭의 [Whisper 켜기]로 받는다. 맥 최신 릴리스는 1.8.2(2026년 9월 25일)로, Whisper 대본에서 영상 맨 끝 단어가 사라질 수 있던 문제를 고쳤다.
