AI로 웹사이트를 만들 때 "글자가 좀 멋있게 나오게 해줘"라고 쓰면 무엇이 나올지 알 수 없다. 효과의 이름을 불러 주면 요청도, 고쳐 달라는 말도 정확해진다. 스레드의 @bokmanhi는 "제목은 타이핑 효과, 설명은 마스크 리빌로 보여줘"처럼 쓰라고 권하면서, 9초짜리 시연 영상에 글자 효과 용어 여덟 개를 담았다. 이 글은 그 여덟 개를 바탕으로 각 효과가 어떤 원리로 움직이는지, 어디에 쓰면 좋고 어디서 방해가 되는지, AI에게 어떻게 요청하면 되는지를 덧붙여 정리한다.

## 이름이 왜 필요한가

AI는 "멋있게"라는 말을 받으면 가장 무난한 답을 고른다. 대개 글자가 살짝 흐려졌다 나타나는 효과 하나가 페이지 전체에 똑같이 붙는다. 마음에 들지 않아 "좀 더 역동적으로"라고 고쳐 달라고 해도, 무엇을 바꿀지는 다시 AI가 짐작해야 한다.

이름은 이 짐작을 없앤다. "타이핑 효과"라고 하면 AI는 글자를 한 자씩 찍고 커서를 깜빡이게 만드는 정해진 방법을 떠올린다. 디자이너와 개발자가 오래 써 온 용어라 AI가 학습한 코드와 설명에도 이 이름이 그대로 붙어 있다. 이름을 아는 것은 AI가 이미 아는 부품 상자의 서랍 이름을 아는 것과 같다.

## 글자 효과 용어 8개

이름과 영문 표기는 시연 영상에 적힌 것을 따랐다. 오른쪽 칸은 화면에서 글자가 움직이는 모습이다.

| 번호 | 이름 | 영문 표기 | 화면에서 보이는 모습 |
|------|------|-----------|----------------------|
| 1 | 타이핑 효과 | Typewriter | 커서가 깜빡이며 글자가 한 자씩 찍힌다 |
| 2 | 단어 교체 효과 | Rotating text | 문장의 틀은 그대로 두고 한 단어 자리만 다른 단어로 차례차례 바뀐다 |
| 3 | 마스크 리빌 | Masked text reveal | 가려져 있던 글줄이 아래에서 밀려 올라오며 드러난다 |
| 4 | 스플릿 텍스트 | Split text | 글자가 하나씩 시간차를 두고 나타난다 |
| 5 | 텍스트 스크램블 | Text scramble | 무작위 문자와 숫자가 뒤섞이다가 원래 단어로 맞춰진다 |
| 6 | 블러 리빌 | Blur reveal | 흐릿하던 글자가 점점 또렷해진다 |
| 7 | 스크롤 텍스트 하이라이트 | Scroll-linked text highlight | 스크롤을 내리는 만큼 단어가 차례로 진해진다 |
| 8 | 형광펜 효과 | Highlighter animation | 글자 뒤로 형광펜 색이 왼쪽부터 그어진다 |

단어 교체 효과는 영문 그대로 "로테이팅 텍스트"라고도 부른다. AI에게 요청할 때는 어느 쪽을 써도 통한다.

## 효과마다 움직이는 원리

원리를 알면 무엇을 조절해 달라고 할지 보인다. 아래 표의 "조절할 것" 칸이 그대로 수정 요청의 어휘가 된다.

| 이름 | 움직이는 원리 | 조절할 것 |
|---|---|---|
| 타이핑 효과 | 자바스크립트가 일정 간격으로 글자를 하나씩 덧붙이고, 오른쪽 세로선이 깜빡여 커서처럼 보인다 | 글자당 속도, 다 친 뒤 커서를 남길지, 지우고 다시 칠지 |
| 단어 교체 효과 | 단어 목록을 정해 두고 몇 초마다 한 단어를 밀어 올리거나 흐리게 바꿔 끼운다 | 단어 목록, 바뀌는 간격, 바뀌는 방식(위로 밀기, 페이드) |
| 마스크 리빌 | 글줄을 넘치는 부분이 보이지 않는 상자에 넣고, 상자 아래에 숨겨 둔 글자를 위로 올린다 | 줄 단위인지 단어 단위인지, 올라오는 속도 |
| 스플릿 텍스트 | 문장을 글자나 단어마다 작은 조각으로 나눈 뒤, 조각마다 시작 시간을 조금씩 늦춘다 | 조각 단위(글자, 단어, 줄), 조각 사이 시간차 |
| 텍스트 스크램블 | 정해진 시간 동안 각 자리에 무작위 문자를 계속 바꿔 넣다가 앞자리부터 진짜 글자로 고정한다 | 섞이는 시간, 섞일 문자 종류 |
| 블러 리빌 | 글자에 흐림 필터와 투명도를 걸어 두었다가 둘 다 서서히 풀어 준다 | 처음 흐림 정도, 풀리는 시간 |
| 스크롤 텍스트 하이라이트 | 화면을 얼마나 내렸는지를 재서 그 비율만큼 앞 단어부터 흐린 색을 진한 색으로 바꾼다 | 시작·끝 지점, 흐린 색과 진한 색 |
| 형광펜 효과 | 글자 뒤 배경색의 너비를 0에서 100퍼센트로 늘린다 | 색, 굵기(글자 높이의 절반만 칠할지), 그어지는 시점 |

## 어디에 쓰고 어디서 피할까

효과는 많이 쓸수록 약해진다. 한 화면에 움직이는 글자가 셋을 넘으면 눈이 어디를 봐야 할지 모른다. 페이지의 첫 화면 제목 하나, 꼭 기억시킬 문구 하나 정도에 아껴 쓰는 편이 낫다.

| 이름 | 어울리는 자리 | 피할 자리 |
|---|---|---|
| 타이핑 효과 | 첫 화면 한 줄 제목, 챗봇처럼 말을 거는 문장 | 긴 설명문. 다 찍힐 때까지 읽을 수 없다 |
| 단어 교체 효과 | "우리 반은 ○○를 배운다"처럼 빈칸 하나를 여러 답으로 보여 줄 때 | 꼭 읽어야 하는 정보. 바뀌기 전에 못 읽은 단어는 놓친다 |
| 마스크 리빌 | 섹션 제목, 스크롤하며 처음 나타나는 큰 글자 | 본문 문단 전체 |
| 스플릿 텍스트 | 짧은 제목, 로고 글자 | 긴 문장. 글자 수만큼 기다리게 된다 |
| 텍스트 스크램블 | 숫자, 코드, 기술 분위기를 내는 짧은 단어 | 한글 긴 문장. 뒤섞이는 동안 의미가 사라진다 |
| 블러 리빌 | 사진 위 제목, 차분한 첫 화면 | 작은 글씨. 흐린 동안 거의 안 보인다 |
| 스크롤 텍스트 하이라이트 | 한 문단짜리 선언문, 이야기 흐름을 따라 읽히고 싶은 글 | 표, 목록, 여러 문단 |
| 형광펜 효과 | 날짜, 가격, 마감처럼 꼭 봐야 할 두세 단어 | 문장 전체. 다 칠하면 아무것도 강조되지 않는다 |

## 움직임을 싫어하는 사람도 있다

움직이는 화면에 어지러움을 느끼는 사람이 있다. 그래서 윈도, macOS, iOS, 안드로이드에는 모두 "동작 줄이기"나 "애니메이션 효과 끄기" 같은 설정이 있고, 웹 페이지는 CSS의 `prefers-reduced-motion`이라는 조건으로 이 설정을 읽을 수 있다. 이 설정을 켠 사람에게는 효과 없이 글자를 바로 보여 주는 것이 기본 예의다.

화면 읽기 프로그램도 고려해야 한다. 스플릿 텍스트나 스크램블처럼 글자를 조각내는 효과는 시각장애인이 쓰는 화면 읽기 프로그램이 글자를 한 자씩 끊어 읽거나 뒤섞인 문자까지 읽게 만들 수 있다. 원래 문장을 통째로 읽히도록 처리해 달라고 함께 요청하면 된다. 학생과 학부모가 보는 학교 페이지라면 특히 빼먹지 않는다.

요청할 때는 이 한 문장을 덧붙이면 충분하다.

> 사용자가 동작 줄이기 설정을 켰으면(prefers-reduced-motion) 모든 글자 효과를 끄고 글자를 바로 보여 줘. 글자를 조각내는 효과는 화면 읽기 프로그램이 원래 문장을 한 번에 읽도록 처리해 줘.

## 바로 쓰는 요청 문장

자리, 이름, 영문 표기, 세부 조건 순서로 적으면 된다. 아래 문장은 그대로 복사해 고쳐 쓸 수 있는 예시다.

| 이름 | 요청 예시 |
|---|---|
| 타이핑 효과 | 첫 화면 제목 "함께 배우는 3학년 2반"을 타이핑 효과(Typewriter)로 보여 줘. 한 글자에 0.08초, 다 치면 커서는 남겨 둬 |
| 단어 교체 효과 | "우리는 ○○를 배운다"의 ○○ 자리에 과학, 음악, 협동이 2초마다 위로 밀려 올라오며 바뀌는 단어 교체 효과(Rotating text)를 넣어 줘 |
| 마스크 리빌 | 각 섹션 제목이 화면에 들어올 때 마스크 리빌(Masked text reveal)로 아래에서 위로 올라오게 해 줘. 줄 단위로 0.6초 |
| 스플릿 텍스트 | 로고 글자를 스플릿 텍스트(Split text)로 한 글자씩 나타나게 해 줘. 글자 사이 시간차는 0.04초 |
| 텍스트 스크램블 | 통계 숫자 "1,248명"이 화면에 들어오면 텍스트 스크램블(Text scramble)로 1초간 섞이다가 맞춰지게 해 줘 |
| 블러 리빌 | 배경 사진 위 제목을 블러 리빌(Blur reveal)로 1초 동안 흐림에서 또렷하게 바꿔 줘 |
| 스크롤 텍스트 하이라이트 | 소개 문단을 스크롤 텍스트 하이라이트(Scroll-linked text highlight)로 만들어 줘. 처음엔 연한 회색, 스크롤하는 만큼 단어가 검정으로 바뀌게 |
| 형광펜 효과 | 신청 마감일 "11월 20일"에만 형광펜 효과(Highlighter animation)를 넣어 줘. 노란색, 글자 아래쪽 절반만, 화면에 보일 때 한 번 |

## 요청하는 순서

1. 효과를 넣을 글자를 먼저 정한다. 제목, 설명문, 가격이나 기간 같은 강조 문구처럼 자리를 짚어 둔다.
2. 표에서 이름을 골라 자리와 짝지어 적는다. "제목은 타이핑 효과, 설명은 마스크 리빌로 보여줘"가 그 꼴이다.
3. 영문 표기를 괄호에 함께 적는다. "마스크 리빌(Masked text reveal)"처럼 쓰면 한글 이름만 적었을 때보다 뜻이 엇갈릴 여지가 줄어든다.
4. 움직임의 세부를 덧붙인다. 속도, 반복 여부, 바뀔 단어 목록, 언제 시작할지(페이지가 열릴 때인지 화면에 보일 때인지)가 여기에 든다.
5. 움직임을 꺼야 할 때를 함께 적는다. 위의 동작 줄이기 문장을 붙여 둔다.
6. 결과를 보고 고칠 때도 이름으로 말한다. "스플릿 텍스트의 글자 간 시간차를 줄여 줘", "형광펜 효과는 '무료 30분'에만 남겨 줘"처럼 쓴다.

## 막히는 곳

효과가 아예 안 보인다면 대개 시작 시점 문제다. "화면에 보일 때" 시작하도록 만든 효과는 이미 화면 안에 있는 첫 화면에서 작동하지 않기도 한다. 이때는 "페이지가 열리자마자 시작해 줘"라고 시점을 바꿔 달라고 한다.

효과가 끝없이 반복돼 산만하다면 "한 번만 실행"이라고 적는다. 대부분의 효과는 반복 여부를 따로 정하지 않으면 AI가 임의로 고른다.

조각내는 효과가 너무 오래 걸린다면 단위를 키운다. 긴 제목을 글자 단위로 나누면 마지막 글자가 나올 때까지 기다리게 된다. "단어 단위로 나눠 줘"라고 하면 조각 수가 줄어 같은 시간차로도 금방 끝난다.

여덟 개를 외울 필요는 없다. 표를 옆에 두고 만들고 싶은 움직임과 가장 가까운 이름을 고르면 된다. 이름만으로 감이 오지 않는 효과는 원 게시물의 영상에서 움직임을 확인한다.
