## AI 코딩, 맥락 오염의 덫

개발 초기에는 명료했던 AI 규칙 파일은 기능 추가와 버그 수정이 반복되며 점점 방대해진다. CLAUDE.md 또는 AGENTS.md 파일 속 규칙들은 중구난방으로 늘어나고, 정리할 시간 부족으로 규칙 간 충돌이 발생한다. 이로 인해 AI는 혼란을 겪고 올바른 추론을 하기 어려워진다.

규칙 파일이 300줄, 500줄 이상 길어지면 다음과 같은 문제가 발생한다.

*   토큰 비용 폭발: 프롬프트 입력마다 불필요한 규칙이 통째로 주입되며 API 비용이 낭비된다.
*   명령 충돌: 서로 다른 페이지에 적힌 규칙들이 충돌하여 AI의 추론 성능이 극도로 저하된다.

이러한 현상은 AI 모델의 지능 자체보다 AI에 전달하는 맥락, 즉 컨텍스트가 오염되어 발생한다.

## 클로드의 해결책: 관리 플러그인

앤트로픽이 공식 제공하는 claude-md-management 플러그인은 클로드 코드(Claude Code) 환경에서 CLAUDE.md 파일의 상태를 진단하고 개선 가이드를 제시하는 라이프사이클 관리 도구이다. 이 플러그인의 핵심 기능은 다음 표와 같다.

| 기능 분류             | 설명                                                                                                                                                                                                                                                        |
| :-------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 자율 진단 및 등급 산정 | CLAUDE.md 파일을 분석하여 명령어(Commands), 아키텍처(Architecture), 패턴(Patterns), 간결성(Conciseness), 최신성(Currency), 실행 가능성(Actionability)의 6가지 품질 지표를 기준으로 C부터 A까지 알파벳 등급을 부여한다.                           |
| 누락 설정 진단    | AI가 자율 코딩을 실행하는 데 필요한 빌드, 린트, 테스트 명령어 등 필수 환경 설정이 빠지면 경고하고 대안을 제안한다.                                                                                                                                       |
| 세션 러닝 반영    | `/revise-claude-md` 명령어를 실행하면 현재 코딩 세션에서 새롭게 발견된 모듈 컨벤션 및 에러 트러블슈팅 지식(Lessons Learned)을 규칙 파일에 자동으로 병합한다.                                                                                 |

이 플러그인은 앤트로픽의 공식 인증을 받았으며, 이미 27만 건 넘게 설치되었다. 이는 많은 개발자가 공통적으로 겪던 문제를 해결하는 유용한 도구임을 증명한다.

## 워크플로우에 플러그인 적용

claude-md-management 플러그인은 다음과 같은 방식으로 개발 워크플로우에 통합한다.

### 1. 클로드 코드 환경에 즉시 도입

클로드 코드 터미널 세션 내부에서 다음 명령을 실행하면 룰 관리 환경을 설정한다.

```
/plugin install claude-md-management@claude-plugins-official
```

설치 후 매주 프로젝트 마감이나 신규 마일스톤 착수 전에 `/revise-claude-md` 명령어를 실행하여 규칙 파일의 상태와 명령어 정합성을 자율 진단한다.

### 2. 고유 에이전트에 유사 스킬 복제

클로드 코드가 아닌 제미나이 CLI (Antigravity)나 자체 구축한 LLM 에이전트 루프를 사용하는 경우, agent-md-management 스킬을 직접 개발하여 적용한다.

*   audit_rules.py: 정규식을 사용하여 규칙 파일 내 필수 실행 명령어가 기재되었는지 스캔하고, 텍스트 줄 수를 200줄 이내로 제한하는 간결성 린터를 구현한다.
*   accumulate_log.py: 일일 작업 회의록(session.md)을 정제하여 AGENTS.md에 단 한 줄의 핵심 교훈으로 자율 병합하는 파이썬 코드를 설정한다.

## 본질은 컨텍스트 엔지니어링

이 플러그인의 핵심은 인공지능에 더 복잡한 지시를 내리기 전에 에이전트가 참조하는 지도의 청결 상태를 점검하는 것이다. 이는 AI에게 더 잘 말하는 기술이 아니라, AI가 읽을 문서를 더 잘 관리하는 컨텍스트 엔지니어링의 한 갈래이다. 스스로 지침의 수준을 관리하고 평점을 매기는 방식으로 AI의 작동 환경을 언제나 깨끗하게 유지한다. 6대 품질 지표는 1인 AI 메이커가 반드시 지켜야 할 엄격한 컨텍스트 위생 표준을 제시한다. 이것이 1인 기업이 속도를 잃지 않고 고품질의 프로덕트를 지속적으로 생산하는 핵심 비결이 된다.
