AI로 영상을 만든다고 하면 보통 영상 생성 모델에 문장을 넣는 장면을 떠올린다. lemo-opuscar 저장소의 영상은 다르다. 화면 하나, 음 하나, 컷 하나까지 전부 코드로 짰다. 영화 스타일 43종을 모아 두었고, 스타일마다 다시 쓸 수 있는 스타일 프롬프트와 클로드 오퍼스 5.5(Claude Opus 5.5)가 코드만으로 만든 짧은 샘플 영상이 한 쌍씩 붙어 있다. 스타일을 하나 고르고 자기 이야기를 주면 코딩 에이전트가 감독을 맡는 구조다. 만든 사람은 Lemomo(LemoLab)이고, 2026년 10월 초 기준 깃허브 별은 859개다.

## 영상 생성 모델 없이 코드로

모든 영상은 AI 에이전트가 코드를 써서 연출하고, 그리고, 음악을 붙이고, 믹싱했다. 화면은 캔버스(Canvas)와 WebGL 페이지를 프레임 단위로 렌더링해 만들고, 음악은 무료 샘플 라이브러리로 직접 작곡하며, 내레이션은 TTS로 입힌다. 영상 생성 모델도 스톡 영상도 쓰지 않는다.

작성자는 이 저장소가 좋은 자료를 모아 둔 어썸 리스트가 아니라고 밝힌다. 모든 영상을 직접 클로드 오퍼스 5.5로 만들었고, 스타일도 오퍼스 5.5에 맞춰 조정했기 때문에 다른 모델로는 같은 결과가 나오지 않을 수 있다.

## 43가지 스타일

스타일은 아홉 갈래로 묶여 있다. 최근 추가된 것은 동판화, SF 홀로그램 화면(HUD), 50년대 평면 카툰, 실크스크린 여행 포스터다.

| 갈래 | 수 | 예시 스타일 |
| :--- | :--- | :--- |
| 손그림·회화 | 7 | 크레용 그림책, 수채화, 수묵화, 임파스토 유화, 한 줄 드로잉, 화이트보드 설명, 펜 담채 어반 스케치 |
| 동아시아 전통 | 4 | 그림자극, 우키요에, 붉은 종이 오리기, 종이 조각 라이트박스 |
| 인쇄·판화 | 5 | 리소그래프, 하프톤 사건 파일, 목판화, 동판화, 실크스크린 여행 포스터 |
| 그래픽·타이포 | 7 | 스위스 모션 그래픽, 60년대 첩보물 타이틀, 아르데코, 청사진, 스테인드글라스, 픽토그램, ASCII·CRT 터미널 |
| 정보·발표 | 5 | 데이터 스토리텔링, 아이소메트릭 인포그래픽, 다크 테크 키노트, 화면 녹화, SF 홀로그램 화면 |
| 카툰·애니메이션 | 4 | 1930년대 러버호스 카툰, 80년대 셀 애니메이션, SF 시트콤 카툰, 50년대 평면 카툰 |
| 게임 | 4 | 16비트 픽셀 RPG, HD-2D, 마이크로게임, 게임쇼 |
| 영화·시대 | 2 | 1920년대 무성영화, 리미널 파운드 푸티지(백룸) |
| 재질·3D | 5 | 블록 장난감, 팝업북, 틸트시프트 미니어처, 로우폴리 섬, 유리 제품 렌더 |

샘플 영상마다 짧은 이야기가 붙어 있다. 화이트보드 설명 스타일의 샘플은 휴대전화가 위치를 아는 원리를 GPS와 원자시계, 상대성이론이 하루에 더하는 38마이크로초로 풀고, 데이터 스토리텔링 샘플은 100년 치 여름 기온을 그래프 자체로 이야기한다.

특별 상영작 OPUSCAR 98은 1927년부터 2025년까지 작품상(Best Picture) 수상작 98편을 6분 31초에 담았다. 클로드 코드 마스코트 Clawd 하나가 98편을 차례로 걸어 지나가고, 각 영화는 그 영화에 맞는 화풍으로 다시 그려진다. 모든 프레임과 음표, 컷을 클로드 오퍼스 5.5가 코드로 썼다. 갤러리 페이지에서 보거나 1080p 파일로 내려받을 수 있다.

## 쓰는 방법

두 가지 방법이 있고, 작성자는 스킬 설치를 권한다. 터미널에서 `claude plugin marketplace add lemomo-ai/lemo-opuscar`와 `claude plugin install lemo-opuscar@lemolab`을 실행하면 어느 폴더에서든 쓸 수 있다. 처음 쓸 때 지침과 도구, 스타일 프롬프트를 `~/lemo-opuscar`에 내려받아 모든 영상이 함께 쓰고, 영상마다의 프로젝트(소스부터 완성본까지)는 작업을 시작한 폴더에 쌓인다. 다른 에이전트에서는 `plugin/skills/lemo-opuscar/` 폴더를 그 에이전트의 스킬 폴더에 복사하면 된다. 두 번째 방법은 저장소를 클론해 그 안에서 클로드 코드를 여는 것이고, 이때 영상은 `films/<이름>/`에 만들어진다.

그다음에는 원하는 것을 말하면 된다. README의 예시는 "우리 가족이 운영하는 커피 농장을 수채화 스타일 45초 영상으로, 따뜻한 여성 내레이터로"와 "유화 임파스토 스타일로 30초짜리 영상, 매일 창가에서 내 퇴근을 기다리는 우리 집 주황 고양이 이야기"다. 스타일 이름은 영어나 중국어로 부르면 되고, 전체 목록은 스타일 색인에 있다.

에이전트는 작업을 시작하기 전에 딱 한 번 묻는다. 주제에서 스스로 정할 수 없는 부분, 사용자에게 직접 준비한 목소리·음악·기타 자료가 있는지, 스토리보드를 먼저 보고 싶은지다. 스토리보드를 원하면 실제 스타일로 그린 핵심 장면을 보여 주려고 한 번 멈추고, 아니면 곧장 완성본까지 간다.

에이전트는 지침 세 개를 읽고 작은 스튜디오처럼 일한다.

| 파일 | 에이전트에게 주는 것 |
| :--- | :--- |
| `DIRECTOR.md` | 연출 방법: 이야기, 소리, 리듬, 카메라, 연기, 자체 점검 |
| `TECHNIQUE.md` | 제작 방법: 프레임 단위 렌더링, 음성, 음악, 믹싱 |
| `styles/<style>/STYLE.md` | 그 스타일의 생김새와 소리. 이야기는 사용자가 정한다 |

## 시작 전에 알아 둘 것

영상 한 편에 에이전트가 30~60분가량 일하고 토큰도 적지 않게 쓴다. Node 20 이상, ffmpeg, Python 3.11 이상(또는 uv)이 있어야 하고 나머지는 에이전트가 설치한다. 기본 출력은 1920×1080, 24fps이고 다른 크기도 요청할 수 있다.

업데이트는 `claude plugin marketplace update lemolab && claude plugin update lemo-opuscar@lemolab` 뒤에 클로드 코드를 다시 시작하면 되고, `~/lemo-opuscar`의 라이브러리는 다음 영상을 만들 때 저절로 갱신된다. 지우려면 `claude plugin uninstall lemo-opuscar@lemolab`을 실행하고 `~/lemo-opuscar`를 삭제한다.

저장소는 MIT 라이선스다. 샘플 영상에 쓰인 제3자 소재는 각각의 라이선스를 따르며(샘플마다 `CREDITS` 참고), 자기 영상에 쓰는 소재의 책임은 사용자에게 있다.
