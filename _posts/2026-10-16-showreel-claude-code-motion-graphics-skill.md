## showreel: AI 기반 모션그래픽 영상 자동화

**showreel**은 앤트로픽의 **Claude Code 스킬**로, 짧은 요청만으로 한국어 모션그래픽 영상을 완성한다. 단순한 템플릿 사용을 넘어, 요청마다 여러 콘셉트 후보를 생성하고 가장 적합한 것을 선택한 뒤 각 영상 구간에 맞춰 새로운 아트 디렉션을 수립한다. 사용자는 오직 영상 주제, 필수 정보, 자료 위치 등 AI가 알 수 없는 사실만 제공하면 된다. 영상의 무드, 길이, 나레이션 여부 같은 창작 결정은 모두 Claude가 내린다.

이 스킬은 광범위한 기능을 하나의 요청으로 통합 처리한다.

| 영역 | showreel의 핵심 기능 |
|---|---|
| **요청 및 콘셉트** | 사용자에게 필수 정보만 묻고, 무드·길이·나레이션 등 창작 결정은 Claude가 수행한다. 3개 이상 콘셉트 후보를 평가하여 최적안을 선정하고, 구간별 아트 디렉션을 `concept.md`에 기록한다. |
| **조사** | 배경 조사를 수행하여 영상에 포함되는 모든 사실에 출처 URL과 신뢰도를 부여한다. 날짜 정보는 달력 기준으로 확인한다. |
| **스크립트** | 화면 표시 텍스트와 발음 텍스트를 분리하고, 영상 길이에 맞춰 스크립트 분량을 조정한다 (예: 60초 영상은 한국어 240~255자 내외). 장면 전환을 위한 큐워드를 지정한다. |
| **나레이션** | 요청 또는 내용에 필요할 때만 사용한다. **ElevenLabs TTS**를 활용하며, 콘셉트에 맞는 목소리를 선택하고 (예: 마커스), 변경된 대사는 해당 부분만 재녹음하며 STT로 발음을 검증한다. |
| **음악 및 효과음** | **ElevenLabs Music**으로 4마디 단위 작곡 계획을 세우며, 비트 분석 후 드롭을 조정한다. 대안으로 NumPy 신시사이저를 사용하고, 24개 프리셋의 효과음 키트도 갖춘다. |
| **이미지** | **codex-image** 스킬로 필요한 장면에만 AI 이미지를 생성한다. 레터박스 제거, 업스케일링, macOS Vision을 이용한 인물 누끼 따기 기능을 제공한다. 실제 인물은 AI로 생성하지 않는다. |
| **모션 엔진** | HTML/JS 기반의 확정적 타임라인(`REEL`)을 사용한다. 모든 프레임은 시간의 순수 함수이므로 병렬 워커로 어떤 순서로든 렌더링할 수 있다. |
| **기법** | 한글 자모 조합, 가변 굵기 파동, 유리 질감 타이포, 파티클 타이포, 매치 컷 등 22가지 검증된 코드 기법과 WebGL2 셰이더, three.js 3D, 사전 계산 시뮬레이션을 활용한다. |
| **렌더링** | **Playwright**와 시스템 Chrome을 사용하여 서브프레임 모션 블러 (180° 셔터), 재개 가능한 청크 렌더링, BT.709 `yuv420p` TV-범위 출력을 지원한다. |
| **믹싱 및 마스터링** | 스피치 대역 음량 감소, 대사별 "나레이션 vs 배경음" 보고서, −14 LUFS 통합 라우드니스와 트루 피크 헤드룸을 위한 2패스 라우드니스 정규화를 수행한다. |
| **비평 루프** | 초안 제출 후 각 영상 구간을 8가지 질문 (템플릿 느낌, 범위, "어떻게 만들었지" 순간, 재료로서의 한글, 프레임 스트립 내 무게감, 리듬, 예측 가능성, 가장 약한 구간) 기준으로 평가하며, `qa/critique_NN.md`에 기록하고 가장 약한 구간은 재작업한다. |
| **자동 QA** | 사양, 라우드니스, 어두운 구간, 광과민성 섬광, 멈춘 화면, 저모션 경고, 최종 믹스의 STT를 점검하여 `qa/qa_report.md`에 보고서를 작성한다. |

**showreel**은 나레이션 단어와 음악 박자에 화면 전환을 프레임 단위로 맞춘다. 최종 결과물은 STT (Speech-to-Text)로 발음을 재확인하고, 음량, 섬광, 멈춘 화면을 검사한 후 납품한다. 인물 프로필, 기업 홍보, 행사, 교육, 티저, 음악 기반 영상 등 13건의 실제 제작에 사용된 방법을 스크립트와 문서로 체계화한다.

다음은 **showreel**을 사용하는 프롬프트 예시이다. 중괄호 부분에는 사용자 자료 링크를 넣는다.

```text
/showreel 역사 데자뷰를 중심으로 책의 내용을 소개하는 30초 영상을 만들어줘. 책에 나오는 역사적 사건들을 연속적으로 이어지는 영상으로 만들어주면 좋겠어. 영상 톤은 옛날 역사영화를 보는 느낌으로. 도서 본문은 여기: {pdf 파일 링크}, 본문에 나오는 역사기록은 여기 모아뒀어: {연대분포 엑셀파일 링크}
엑셀파일 내용을 참값으로 간주하고 만들어. 내 캐릭터는 이 이미지의 왼쪽 위에 있는 인물이야: {가족 캐릭터 그림 링크}
이 이미지로 기존에 만든 장면들은 여기 있는 그림들을 참고해: {도서 삽입그림 링크}
```

## iso-reel: 인터랙티브 모션그래픽 쇼케이스 도시

**iso-reel**은 모션 디자이너의 쇼릴을 아이소메트릭 도시 형태로 구현한 웹 애플리케이션이다. 도시 내 각 건물은 하나의 모션그래픽 영상 작품을 상징한다. 도시는 창 불빛, 차량 움직임, 크레인, 지면 박동, 건물 재배치 등 다양한 요소로 끊임없이 움직인다. 사용자가 특정 건물을 선택하면, 화면이 해당 건물로 확대되어 영상이 재생된다. 이 프로젝트는 **Vite, three.js, GSAP**를 기반으로 한 정적 웹사이트로 **GitHub Pages**를 통해 배포된다.

사용자는 아래 표의 조작법으로 도시를 탐색하고 영상을 재생한다.

| 입력 | 동작 |
|---|---|
| 드래그(마우스·한 손가락) | 지도처럼 이동하며 관성을 갖는다 |
| 휠·핀치 | 커서 위치를 기준으로 화면을 확대·축소한다 |
| `Q` / `E`, 회전 버튼 | 도시를 90° 회전한다 |
| 방향키 / `WASD` | 도시를 이동한다 |
| `Tab` / `Shift+Tab`, `[` / `]` | 다음·이전 건물로 이동한다 |
| `Enter` / `Space` | 선택한 건물의 영상을 재생한다 |
| `1`~`9` | 해당 번호의 건물로 이동한다 |
| `L` | 목록 보기 모드를 전환한다 |
| `Esc` | 플레이어 또는 패널을 닫는다 |
| `?` | 조작 도움말을 표시한다 |

플레이어 안에서 영상을 제어하는 단축키도 존재한다. `Space`로 재생·일시정지하고, `←` / `→`로 5초씩 이동한다. `M`은 음소거, `F`는 전체 화면 전환, `[` / `]`는 이전·다음 영상으로 이동하는 기능을 수행한다. 영상이 끝나면 2초 뒤 자동으로 다음 영상으로 전환되며, 이 기능은 사용자가 끌 수 있다.

**iso-reel**은 다양한 기술과 기법으로 제작된 9가지 샘플 쇼릴 영상을 포함한다. 모든 영상은 15초, 1920×1080, 30fps 규격이다.

| 번호 | 제목 | 기법 | 제작 도구 | BPM |
|---|---|---|---|---|
| 01 | 쇼릴 2026 | 비트 컷 몽타주와 키네틱 타이틀 카드 | HTML 컴포지션, Canvas 2D, FFmpeg | 128 |
| 02 | 한글, 움직이다 | 자모 조립 키네틱 타이포와 가변 굵기 비트 싱크 | Canvas 2D, fontTools, 가변 폰트 | 128 |
| 03 | 서울 24시 | 미니어처 도시 라이팅 타임랩스와 HUD 합성 | Blender(EEVEE), HTML 컴포지션 | 96 |
| 04 | 숫자의 맥박 | 자기 참조 인포그래픽(실제 프로젝트 데이터) | Canvas 2D, JavaScript | 144 |
| 05 | 빛의 입자 | GPU 인스턴싱 파티클 글자 형성·폭발·재형성 | Unity, Python, HTML 컴포지션 | 112 |
| 06 | 한 잔의 아침 | 실사 2.5D 패럴랙스와 원형 매치 컷 커머셜 | codex-image, WebGL(three.js), rembg | 80 |
| 07 | 리듬의 격자 | 음악 싱크 제너러티브 타일 격자 | Canvas 2D, JavaScript | 160 |
| 08 | 손끝의 흐름 | 3D 폰 목업 위 UI 전환과 마이크로 인터랙션 | HTML, CSS 3D, SVG | 112 |
| 09 | 유리 활자 | 유리·크롬 입체 한글의 굴절 라이팅 | Blender(Cycles), HTML 컴포지션 | 64 |

이 영상들은 HTML 컴포지션, Blender, Unity 등 다양한 제작 도구를 활용하여 만들었다. 마스터는 H.264 1080p30, 정확히 15초, 라우드니스 -14 LUFS로 인코딩했다. 배경 건물과 소품 키트의 표면은 **투영 베이크 텍스처** 기법을 사용하여 만들었다. 상자 모델 렌더링, AI 이미지 생성, 실루엣 맞추기, 방향별 이미지 투영 및 가중 합성, UV 아틀라스 굽기 과정을 거친다. 음악과 효과음은 외부 샘플 없이 NumPy와 SciPy 신시사이저를 사용하여 **절차적으로 합성**한다. 최종 믹스의 라우드니스와 트루 피크는 측정 스크립트로 검증한다. 출고 전에는 WCAG 2.3.1을 단순화한 **섬광 안전 검사 스크립트**를 사용하여 광과민성 반응 위험을 확인한다.

## AI 기반 영상 제작과 인터랙티브 쇼케이스의 결합

**showreel**은 AI 기술로 영상 제작의 효율성과 접근성을 극대화한다. 전문 지식 없이도 복잡한 모션그래픽 영상을 만들 수 있는 가능성을 보여준다. **iso-reel**은 단순히 완성된 영상을 보여주는 것을 넘어, 사용자가 몰입하여 탐색하고 경험하는 새로운 방식의 쇼케이스를 제시한다. 이 두 프로젝트는 AI가 콘텐츠 제작 과정 전반과 최종 전달 방식 모두에 깊이 관여하며, 창작자와 사용자 모두에게 혁신적인 경험을 제공하는 미래를 그린다.
