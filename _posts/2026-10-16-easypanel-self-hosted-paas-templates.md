Easypanel은 내 서버에 직접 만든 앱이나 오픈소스 서비스를 배포하고 운영하는 셀프호스팅 PaaS(Platform as a Service)다. 홈페이지는 '현대적인 셀프호스팅 PaaS'를 내세우며, 아무것도 없는 상태에서 서비스가 돌아가기까지 몇 분이면 된다고 소개한다. 가장 눈에 띄는 것은 템플릿 카탈로그다. 템플릿 페이지에는 오픈소스 도구를 클릭 한 번으로 설치하는 템플릿 845개가 올라와 있다.

## Easypanel은 어떤 도구인가

홈페이지에 따르면 Easypanel은 66,000대가 넘는 활성 서버에서 돌아가고 있다. 선도적인 클라우드 업체와 호스팅 파트너들이 자기 고객의 인프라를 운영하는 데 Easypanel을 쓴다고도 적었다. 페이지 하단에는 '145,000명이 넘는 셀프호스터와 함께하라'는 문구와 함께 무료 요금제가 있고 신용카드가 필요 없다는 안내가 붙어 있다.

특정 호스팅 업체에 묶이지도 않는다. 요금 페이지 FAQ는 지원되는 리눅스 배포판이 돌아가는 VPS나 전용 서버라면 어디서든 쓸 수 있다고 답하고, Hetzner, DigitalOcean, AWS를 예로 든다. 홈페이지에는 서버 컨트롤 패널 고르기, 셀프호스팅과 매니지드 PaaS 비교, VPS에 Docker 앱 배포하기 같은 셀프호스팅 가이드도 함께 실려 있다.

## 템플릿 수는 페이지마다 다르게 적혀 있다

템플릿 페이지 상단에는 '845 one-click installers'라고 적혀 있고, 페이지에 실린 템플릿 목록도 845개다. 홈페이지는 '750+ open-source services', '750+ apps, one click'이라고 쓰고, 요금 페이지의 기능 설명은 '790+ built-in templates'라고 쓴다. 이 글의 845개는 템플릿 페이지 기준이다.

## 템플릿 카탈로그

템플릿 페이지의 첫 문구는 'Your next app is already packaged', 다음에 쓸 앱은 이미 포장돼 있다는 뜻이다. 익숙한 오픈소스 도구를 고른 뒤 몇 분 안에 내 서버에 배포하라는 안내가 이어진다. 홈페이지도 인기 있는 오픈소스 도구를 설정까지 마친 상태로 몇 분 안에 내 서버에서 돌릴 수 있다고 설명한다. 요금 페이지를 보면 원클릭 템플릿은 무료 요금제를 포함한 모든 요금제에서 쓸 수 있다.

카테고리 필터는 전체(All)와 생산성(Productivity), 개발 도구(Developer Tools), 분석(Analytics), 자동화(Automation), 미디어(Media), AI, 데이터베이스(Database)로 나뉜다. 목록 맨 앞에는 2FAuth(Google Authenticator 같은 OTP 생성기를 대신하는 웹 기반 셀프호스팅 도구)와 4ga Boards(Trello에서 영감을 받은 칸반 보드 협업 도구)가 있다. 익숙한 이름도 많다. 몇 가지를 골라 템플릿 페이지의 설명을 옮기면 다음과 같다.

| 템플릿 | 템플릿 페이지 설명 |
|---|---|
| Nextcloud | Files, Talk, Groupware, Office 네 제품을 하나로 묶은 Nextcloud Hub 5. 협업 흐름을 최적화하도록 설계됐다 |
| Grafana | 메트릭, 로그, 트레이스 데이터를 시각화하는 오픈소스 플랫폼. 데이터를 조회하고 시각화하고 알림을 걸 수 있다 |
| Supabase | Postgres 위에 만든 오픈소스 Firebase 대안. 설정과 사용이 쉽고 무료이며 완전한 오픈소스다 |
| Immich | 개인과 가족을 위한 셀프호스팅 사진·동영상 백업 도구. 자동 업로드 같은 기능을 갖췄다 |
| n8n | 기술 사용자를 위한 워크플로 자동화 도구. API와 씨름하지 않고 복잡한 자동화를 10배 빠르게 만든다고 소개한다 |
| Activepieces | 코딩 없이 쓰는 오픈소스 업무 자동화 도구. Zapier의 대안이다 |
| Ollama | 고급 AI 모델의 배포와 사용을 단순하게 만드는 도구. 대규모 언어 모델(LLM)을 관리하고 호스팅한다 |
| Plausible | 가볍고 단순한 오픈소스 웹 분석 도구. 개인정보를 존중하는 Google Analytics 대안이다 |
| Uptime Kuma | 웹사이트 가동 상태를 추적하는 셀프호스팅 모니터링 도구. HTTP(s), TCP, Ping, DNS 레코드 등을 감시한다 |

## 주요 기능

홈페이지는 셀프호스팅에 필요한 기능을 배포, 보안, 백업, 지원, 모니터링, 데이터베이스 여섯 갈래로 소개한다. 요금 페이지의 기능표와 함께 보면 어디까지가 무료 요금제에 들어 있는지도 알 수 있다.

### 배포

GitHub에 코드를 푸시하면 앱이 자동으로 배포되고, 모든 배포는 무중단(zero-downtime)으로 이뤄진다. 홈페이지는 배포 파이프라인을 네 단계로 보여 준다.

| 단계 | 홈페이지 설명 |
|---|---|
| Git Push | main 브랜치에 커밋 푸시 |
| Build | 컨테이너 이미지 빌드 |
| Health Check | 무중단 교체(swap) 확인 |
| Live | 새 버전으로 트래픽 전환 |

요금 페이지에 따르면 서비스 종류는 App(애플리케이션 서비스), Box(컨테이너 작업 공간), Compose(다중 컨테이너 스택), WordPress(관리형 WordPress) 네 가지다. 빌드는 Dockerfile, Nixpacks, Buildpacks, Railpack 가운데 골라 옵션을 조정한다. 자동 배포와 웹훅, 서비스별 도메인 연결과 호스트·경로 라우팅, 내장 Traefik 미들웨어 13종, Cloudflare Tunnel을 이용한 서비스 노출은 무료 요금제를 포함한 모든 요금제에 들어 있다.

### 보안

SSL 인증서는 자동으로 갱신되고 2단계 인증(2FA)을 지원한다. 요금 페이지 설명으로는 Let's Encrypt 인증서를 무료로 자동 발급하고 갱신한다. 두 기능 모두 모든 요금제에 포함된다.

### 백업

홈페이지는 앱, 볼륨, 데이터베이스가 자동으로 백업되고 클릭 한 번으로 복원된다고 소개하며, 백업 대상으로 AWS S3, Google Drive, Dropbox를 보여 준다. 요금 페이지의 설명은 범위가 더 넓다. 데이터베이스 백업은 일정을 정해 S3 호환 스토리지, Dropbox, Google Drive, FTP/SFTP, 로컬 저장소로 보낼 수 있고 복원도 지원한다. 다만 데이터베이스 백업과 볼륨 백업은 Hobby 이상 유료 요금제에만 있다.

### 모니터링

서비스별 CPU, 메모리, 디스크, 네트워크 사용량을 실시간으로 보여 주고, 로그와 셸이 내장돼 있다. 요금 페이지 기준으로 무료 요금제의 기본 모니터링은 서버 전체의 CPU·메모리·디스크 사용량 개요다. 서비스별 지표와 네트워크 I/O, 실시간 모니터링 대시보드는 Hobby 이상에서 쓰는 고급 모니터링에 속한다.

### 데이터베이스

Postgres, MySQL, MongoDB, Redis를 일급 서비스로 다루며, 몇 초 만에 하나를 만들 수 있다. 요금 페이지는 여기에 MariaDB를 더해 관리형 데이터베이스와 내장 관리 도구를 제공한다고 적는다.

### 지원

홈페이지는 제품을 잘 아는 사람이 팀에서 직접 돕는 전담 지원을 내세운다. 요금 페이지 FAQ를 보면 팀이 직접 응대하는 지원은 Business 요금제에 해당하고, 나머지 요금제는 Discord 커뮤니티에서 지원한다.

## 요금제

요금 페이지는 무료로 시작해 성장에 맞춰 확장하라고 권하며, 서버 단위로 결제하고 언제든 해지할 수 있다고 적는다. 유료 요금제 가격은 서버 한 대당 월 요금이다. 페이지를 열면 연간 결제가 기본으로 선택돼 있어 Hobby $10.9, Growth $16.9, Business $29.9가 보이고, 월간 결제로 바꾸면 $14.9, $23.9, $37.9로 바뀐다. 페이지는 연간 결제 시 최대 33%를 아낄 수 있다고 표기한다.

요금제마다 붙은 한 줄 소개는 이렇다. Free는 영원히 무료인 넉넉한 요금제, Hobby는 1인 운영을 한 단계 끌어올리는 요금제, Growth는 팀 전체가 함께 일하는 요금제, Business는 회사를 위한 전담 지원 요금제다. 상위 요금제는 바로 아래 요금제의 기능을 모두 포함한다.

| 항목 | Free | Hobby | Growth | Business |
|---|---|---|---|---|
| 서버당 월 요금(연간 결제) | $0 | $10.9 | $16.9 | $29.9 |
| 서버당 월 요금(월간 결제) | $0 | $14.9 | $23.9 | $37.9 |
| 프로젝트 | 3개까지 | 무제한 | 무제한 | 무제한 |
| 서비스·배포 | 무제한 | 무제한 | 무제한 | 무제한 |
| 원클릭 템플릿, 자동 SSL, 2FA | 포함 | 포함 | 포함 | 포함 |
| 기본 모니터링 | 포함 | 포함 | 포함 | 포함 |
| 고급 모니터링 | 없음 | 포함 | 포함 | 포함 |
| 알림 | 없음 | 포함 | 포함 | 포함 |
| 데이터베이스·볼륨 백업 | 없음 | 포함 | 포함 | 포함 |
| 서비스용 사용자 도메인 | 없음 | 포함 | 포함 | 포함 |
| API, MCP, CLI | 없음 | 포함 | 포함 | 포함 |
| 다중 사용자, 프로젝트별 접근 제어 | 없음 | 없음 | 포함 | 포함 |
| 클러스터 지원(알파) | 없음 | 없음 | 없음 | 포함 |
| 화이트 라벨링(로고 교체·코드 삽입, 오류·점검 페이지 브랜딩) | 없음 | 없음 | 없음 | 포함 |
| 지원 | 커뮤니티 | 커뮤니티 | 커뮤니티 | 커뮤니티 + 우선 지원 |

표의 몇 가지 항목은 요금 페이지 설명을 덧붙여야 뜻이 분명해진다. 서비스용 사용자 도메인은 서비스 주소에 기본값 대신 내 와일드카드 도메인을 쓰는 기능이다. 서비스마다 도메인을 연결하는 기능 자체는 무료 요금제에도 있다. 알림은 배포, 백업, 디스크 사용량 소식을 Discord, Slack, Telegram, SMTP, 웹훅으로 보낸다. MCP는 호환되는 AI 클라이언트를 Easypanel의 원격 MCP 서버에 연결해 Easypanel을 조회하고 관리하게 한다. 클러스터 지원은 워커 노드를 붙여 여러 서버를 하나의 클러스터로 관리하는 기능으로, 아직 알파 단계다. 서버 이름과 강조 색상 바꾸기는 모든 요금제에서 된다.

FAQ에 따르면 라이선스 하나는 서버 한 대(노드, VM, 인스턴스)에서 Easypanel을 쓸 권리이고, Easypanel을 돌리는 서버마다 라이선스가 따로 필요하다. 체험판이 있느냐는 질문에는 무료 요금제만으로도 제품을 충분히 써 볼 수 있고, 유료 요금제에는 30일 환불 보장이 있다고 답한다. 결제는 LemonSqueezy가 처리하며 카드와 PayPal 등을 받는다. 구독을 해지하면 Easypanel은 무료 요금제로 계속 동작하고, 기존 프로젝트도 그대로 돌아간다.
