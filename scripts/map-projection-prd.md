# 지도 도법 교육 웹앱 (/tools/map-projection/) — 분석 및 개선 PRD

작성 2026-09-06. 대상: `tools/map-projection/index.html` (v1, 커밋 6381027).
v1 기능: 메르카토르·갈-페터스·로빈슨·정거원통 ↔ Equal Earth 나란히 비교, 나라 클릭 시
면적 왜곡 배수 readout, 그린란드 스포트라이트, 성찰 질문 4개(localStorage), embed/딥링크.

## 1. 종합 분석 (장점 / 단점)

### ① 실제 교육적 기능
- 장점: 왜곡을 **배수 수치로 즉각 피드백**(추상 개념의 구체화). 도법 4종 전환으로 "지도마다 다르다"를
  한 화면에서 비교. 스포트라이트가 대표 오개념(그린란드≈아프리카)을 정면 공략.
- 단점: 다루는 왜곡이 **면적 1종뿐** — 형태·거리·방향 왜곡 부재. 메르카토르의 존재 이유(각도 보존=항해,
  웹 지도 타일 표준)를 체험할 수 없어 **"메르카토르=나쁜 지도"라는 역오개념** 위험.
  임의의 **두 나라 직접 비교 불가**(스포트라이트 1종뿐). 아프리카는 대륙이라 클릭 불가 →
  14배 주장을 앱 안에서 검증 못 함. 티소 지시원 같은 왜곡 방향 시각화 없음.

### ② 수업에서의 활용도
- 장점: 설치·로그인 없음, URL 하나, 무료, 모바일 대응. embed·`?spot`·`?sel` 딥링크로 교사가
  특정 상태를 바로 제시 가능.
- 단점: **교사용 자료 부재** — 차시 흐름·발문 예시·기대 반응·평가 관점이 없어 "도구만 있고 수업 설계가 없다".
  학생 답이 localStorage에만 있어 **수집·공유·증빙 불가**(내보내기 없음). 딥링크 사용법 미문서화.
  **CDN 의존(unpkg·world-atlas)** — 학교망이 unpkg 차단 시 전면 불능, 오프라인 불가.
  작은 나라의 터치 히트 영역이 좁아 태블릿에서 선택 어려움. 학교급별 어휘 조절 없음('도법'·'등적').

### ③ 학생의 사고 및 학습 효과
- 장점: 수치(6.8배)가 인지 갈등 유발. 열린 성찰 질문이 정답 찾기 회피. 색·수치·막대의 다중 표상.
- 단점: **예측 단계가 없다** — 클릭하면 바로 답이 나와 "수동적 확인"이 됨(생성 효과·예측 오류 기반 학습 미활용).
  질문 4개가 탐구와 분리되어 첫 화면부터 병렬 노출(활동↔성찰 연결 약함). 또래 답과 비교·반례 검토 장치 없음.
  "그럼에도 왜 아직 메르카토르를 쓰는가"를 다루지 않아 비판이 단순 고발에서 멈출 수 있음.

### ④ 교사의 수업 가이딩
- 장점: 스포트라이트 버튼이 도입 발문으로 즉시 사용 가능. 질문 태그(프레임/인식/관점/편향)가
  수업 목표와 1:1 매핑.
- 단점: 교사 모드 없음(발문 순서, 시간 배분, 예상 오답, 루브릭). 질문 편집·추가 불가(고정 4문항).
  인쇄용 활동지 없음. 전체 학생 화면을 같은 상태로 맞추는 방법이 문서화되지 않은 딥링크뿐.

### ⑤ 학습과학 측면
- 장점: 즉각 피드백, 이중 부호화(수치+색+공간), 구체 사례 고정(anchoring), 자기 설명 촉진.
- 단점: **생성 효과 미활용**(예측→확인 루프 없음). 1회성 체험 — 인출 연습·간격 반복 없음.
  안내된 탐구(guided inquiry) 시퀀스 부재: 초심자에게 자유 탐색은 비효율(최소 안내 수업 비판과 동일 지점).
  사전/사후 오개념 진단 없음 → 학습 효과를 스스로도 확인 못 함. 전이를 노리는 4번 질문이 있으나
  지도 밖 실제 사례(그래프 축 조작, 뉴스 프레이밍)로 잇는 콘텐츠는 없음.

### ⑥ 디자인 측면
- 장점: 아틀라스 정체성(종이+격자+세리프)이 주제와 일치, AI 슬롭 회피. 색이 의미를 가짐
  (테라코타=과대, 청록=실제). embed 모드·자동 높이. 반응형.
- 단점: **접근성** — 키보드로 나라 선택 불가(클릭 전용), readout에 aria-live 없음,
  테라코타/청록이 적록색약에서 변별 저하(색+패턴 병용 필요). 로딩 상태 표시가 약해 CDN 지연 시 빈 지도.
  모바일에서 클릭→readout이 화면 밖(스크롤 필요). 국가명 한글화가 55개 하드코딩(나머지 영어 노출).

## 2. 개선 계획 (우선순위)

### Phase 1 — 학습 효과 핵심 (높은 효과·낮은 비용) ✅ 2026-09-06 구현 완료
(예측 모드·두 나라 비교·교사 가이드·답 내보내기·접근성 5종 반영. 딥링크 `?cmp=A,B`(비교 프리셋)·
`?ask=Name`(전체 학급 예측 투표)도 추가.)
1. **예측 모드**: 나라 클릭 시 바로 답을 주지 않고 "실제보다 크게? 작게? 비슷하게?" 3버튼 추측 후 공개.
   추측-실제 일치 여부 기록(세션 통계 "n개 중 m개 적중"). 생성 효과+인지 갈등의 구조화.
   기본 ON, `?nopredict`로 끔(교사 시연용).
2. **두 나라 비교 모드**: 두 나라를 연속 선택 → "지도에서는 A:B ≈ x:1, 실제로는 y:1" 병렬 readout +
   두 지도 동시 하이라이트. 그린란드 스포트라이트를 이 일반 기능의 프리셋으로 흡수.
3. **교사용 가이드(접이식)**: 40분 차시 흐름(도입 스포트라이트 5' → 예측 탐구 15' → 성찰 질문 12' → 공유 8'),
   발문 예시, 예상 반응, 딥링크 치트시트. 페이지 하단 `<details>`로.
4. **답 내보내기**: 성찰 답 4개를 "복사하기 / .txt 내려받기" — 패들릿·과제 제출로 이동 가능(증빙).
5. **접근성 기본기**: 나라 path에 tabindex+Enter 선택, readout `aria-live=polite`,
   선택 표시에 색+해칭 패턴 병용, 로딩 스피너 문구.

### Phase 2 — 균형 잡힌 관점·수업 적합화 ✅ 2026-09-06 완료
(#6 "왜 아직 메르카토르인가" 균형 섹션, #7 티소 지시원 '왜곡 눈금' 토글, #8 초등/일반 수준 전환,
#9 라이브러리·지도 데이터 self-host(`tools/map-projection/vendor/`, ~445KB) 모두 반영. 교사용 가이드는
딥링크 안내를 빼고 상단 우측 소형 트리거→모달로 이동해 학생 눈에 덜 띄게 배치.)
6. **"그런데 왜 아직 메르카토르인가" 섹션**: 각도 보존(항정선 직선) 미니 데모 또는 도해 + 웹 지도 타일
   표준 이야기. "도법=목적에 따른 선택"으로 착지시켜 역오개념 차단.
7. **티소 지시원 토글**: 왜곡의 크기·방향을 원의 변형으로 시각화(d3 geoCircle로 구현 가능).
8. **수준 전환(초등/중등·성인)**: 어휘(도법→지도 그리는 방법)와 질문 문구 2벌.
9. **오프라인 번들**: d3·topojson-client·d3-geo-projection·countries-110m.json을 저장소에 동봉
   (총 ~700KB). 학교 방화벽·오프라인 대비. CDN은 폴백으로 강등.

### Phase 3 — 확장 ✅ 2026-09-06 (#10·#12 완료, #11 보류)
10. ✅ 드래그 "진짜 크기" 모드: '진짜 크기 끌기'에서 나라를 클릭→끌면 위도별 sec 비율로 실시간 재계산(적도로 갈수록 축소). 딥링크 `?drag=Name`.
11. ⏸ 교실 수합: 서버가 필요해 정적 tools 페이지 범위 밖으로 **보류**. 현재는 '답 복사/내려받기'로 과제·패들릿 제출을 대체. 추후 dotconnector-ask 패턴으로 별도 구현 검토.
12. ✅ 자가 점검 퀴즈: 사전/사후 대신 '스스로 점검하기' 3문항(즉시 피드백·해설·점수)으로 인출 연습·오개념 확인.

### 추가 반영 — 실제 크기 겹쳐보기 & 아프리카 착시 (2026-09-06)
- "땅덩어리 비교가 직관적이지 못하다 → 극적으로 확대해서 보게" 피드백 반영. 세계지도 위 하이라이트에 더해
  **같은 배율로 포갠 실제 크기 오버레이 패널**(등적 방위도법·공유 스케일)을 추가해 왜곡 없는 진짜 크기를 확대 비교.
  - 두 나라 비교 → 큰 쪽 옅게·작은 쪽 진하게 가운데 포갬 + 배수 캡션(예: 호주가 그린란드의 3.5배).
  - 그린란드 착시 → 아프리카 위에 그린란드(약 1/14).
  - **아프리카 착시 버튼 신설** → 아프리카 안에 미국·중국·인도(합계 약 73%) 포갬. 세계지도 highlight도 함께.
- 스포트라이트를 '그린란드 착시'·'아프리카 착시' 2버튼으로 정리(vs 이름 오해 해소). 딥링크 ?africa 추가.

### 다듬기 — 겹쳐보기 정합성·한글 줄바꿈·초등 어투 (2026-09-06)
- **아프리카 겹쳐보기 넘침 제거**: 미국은 `mainland()`(MultiPolygon 최대 폴리곤)로 **본토만** 그려 알래스카·하와이(패널 밖으로 튀던 점들)를 제거. 세 나라 위치를 재조정해 아프리카 윤곽 안에 안착, 라벨 충돌도 해소(중국 라벨 위쪽 배치). 캡션 %는 그려진 본토 면적으로 계산(약 68%, 정직).
- **한글 고아 단어·줄 개선**: `body`에 `word-break:keep-all`(어절 중간 끊김 방지 — 한글 줄바꿈 근본 해결) + `text-wrap:pretty`, 헤딩·질문·플레이트명에 `text-wrap:balance`.
- **초등용 쉬운 말 친절화**: basic 레벨 도입·안내·성찰 질문·균형 섹션을 따뜻한 해요체로 재작성. 예측 발문·결과 readout·정오답 피드백도 basic일 때 해요체+쉬운 어휘(면적 비중→크기)로 분기.

### 모바일 최적화 & 진짜 크기 끌기 버그 수정 (2026-09-06)
- **모바일**: 스포트라이트 버튼 한 줄 균등 분할(`.spots{width:100%};.spot{flex:1}`), `@media(max-width:480px)`에서 `.ovlab` 폰트·halo 상향(SVG viewBox 단위라 좁은 화면에서 라벨이 작아지던 문제)·컨트롤/seg/readout 여백 축소. 검증은 390px iframe 하네스 Edge 캡처(window-size 최소폭 아티팩트 회피).
- **진짜 크기 끌기 3종 버그**: ① 그룹 전체 transform → 점선(원래 자리)까지 이동 → 사본(live) 패스에만 transform. ② 잡는 순간 커서로 순간이동 → d3.drag 절대좌표 대신 상대 이동(ev.dx/dy) 누적. ③ home에서 133% 표시 → 위도 기준을 geoCentroid(구면)가 아닌 '픽셀 중심 역투영'으로 통일(드래그 중 측정과 동일 → home=100%). d3.drag는 헤드리스 합성 이벤트로 안 열려서 초기 렌더(home=100%)로 검증.
